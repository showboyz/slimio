How to compress a PDF for email

  • 1. Add your PDF. The target is preset to 10MB, which gets through almost any mail server.
  • 2. Pick a limit if you know it — see the table below — and click Compress.
  • 3. Download and attach.

Email attachment limits

  • Gmail: 25MB of attachments for personal accounts. Above that, Gmail replaces the file with a Google Drive link.
  • Outlook.com: 25MB. Bigger files can be shared from OneDrive instead (up to 2GB).
  • Work email (Microsoft 365): 35MB to send and 36MB to receive by default, and admins can set anything from 1MB to 150MB. The recipient's server limit applies too.

Why a file under the limit can still bounce

Attachments are encoded for sending, which makes them larger in transit — we attached a 6.04MB PDF to a message and the message came to 8.16MB, about 1.35 times the file. A PDF close to the recipient's limit can be rejected. Aim for a file comfortably below it — 10MB is a safe choice when you don't know the recipient's setup.

Sending several documents?

Combine them with Merge PDF first, then compress once. If one message still can't fit everything, use Split PDF and send the parts in separate emails.

Compress PDF for Email — FAQ

How do I make a PDF small enough to email?

Drop it on this page and click Compress. The default 10MB target fits nearly every email service. The compressed PDF downloads right away.

What size should a PDF be for Gmail?

Personal Gmail accounts can attach up to 25MB. Above that, Gmail sends a Google Drive link instead of the file. To send the file itself, keep it under 25MB — or pick 10MB so the recipient's server has room too.

Why was my email rejected even though the file is under the limit?

The recipient's mail server may have a smaller limit, and attachments grow when encoded for sending. Compress to 10MB or less.

Will the recipient see a lower-quality PDF?

SlimIO keeps text sharp whenever it can and only reduces image detail as much as needed. For typical documents the difference is hard to notice.

Is there a size limit for the file I upload?

Files up to 50MB get text-preserving compression on our server. Larger files are compressed entirely in your browser.
