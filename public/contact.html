Reporting a problem

If a file doesn't come out as expected, these details help find the cause quickly:

  • Which tool or page you used (the address in your browser is perfect).
  • Your device and browser — for example "Android phone, Chrome" or "Windows laptop, Edge".
  • What you expected and what happened instead, including any error message. A screenshot helps.
  • For PDFs: roughly how many pages and how big the file was, and whether it was a scan.

Please don't attach files that contain personal information — ID cards, certificates, signed contracts. A description or a sample without personal details is enough.

A size rule has changed

Exam and agency requirements change between notifications. If a preset or a guide shows a number that no longer matches the official notice, send the name of the exam and a link to the notice, and it will be updated.

Ideas and requests

Missing a tool, a size preset for your exam, or a language? Tell us what you were trying to do. Several of the current tools were added after seeing what people were trying to do with their files.
