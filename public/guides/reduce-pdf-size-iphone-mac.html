How to reduce PDF size on iPhone and Mac: the built-in options, tested

By SlimIO · Updated October 11, 2026 · 5 min read

A PDF made from phone photos is big for a simple reason: every page is a 12-megapixel photo. Our three-page test document, at that size, came to 7.4 MB, far over the 1MB or 2MB limit many upload forms set. Apple gives you two built-in ways to shrink a PDF, Preview on the Mac and a Shortcuts action on iPhone, so we ran both on the same files, next to SlimIO, and measured what came out.

Tested on a Mac running macOS 27 in October 2026, with three PDFs we made for the test. The Shortcuts action is the same one the Shortcuts app offers on iPhone and iPad, but we ran it on the Mac.

The three test files

  • Photos of a paper document: a 3-page rental agreement made to look like phone photos of paper (one 3024 × 4032 JPEG per page, the 12-megapixel size phone cameras commonly save) and saved as one PDF, 7.4 MB. This is what most "my PDF is too big" problems look like.
  • Screenshots: three phone screenshots (PNG) saved as a PDF, 655 KB.
  • A text-only report: 4 pages of text, headings, a table and a chart, saved as PDF from a browser, 61 KB.

Sizes are as Finder shows them (1 KB = 1,000 bytes). "No change" means the file came out within 1 KB of the original. We also ran a Korean version of the text report through Preview: it grew from 101 KB to 667 KB, and its text could no longer be selected or searched, because the filter had turned every letter into drawn shapes.

On a Mac: Preview's Reduce File Size

This is the method Apple documents for the Mac:

  1. Open the PDF in Preview.
  2. Choose File > Export (not Export as PDF).
  3. In the Quartz Filter pop-up menu, choose Reduce File Size.
  4. Give the file a new name, so you keep the original, and click Save.

On macOS 27 the filter's settings file asks for images at 144 pixels per inch, at most 2,400 pixels on a side, saved as JPEG at quality 0.7. That explains the results: it does a fair job on photos, though its JPEG setting leaves the file about three times larger than SlimIO's at a similar resolution. It doesn't stop at the photos, though. It rewrites the whole file, and on our text PDFs that made things worse. Compare the new file with the original before you delete anything.

Apple also lists three checkboxes in the same Export dialog: Create Linearized PDF, Optimize images for screen and Save images as JPEG. They are worth a try on a photo-heavy file, with the same rule: check the size afterwards.

On iPhone and iPad: the Shortcuts action

The built-in way on iPhone is an action in the Shortcuts app called Optimize File Size of PDF. Apple's own description of it is careful: it "optimizes the file size of the provided PDF file by compressing its images. If the images contained in the PDF are already compressed, this action might not have a measurable effect on file size."

That warning matched what we saw. Photos from a phone are already JPEGs, and the action left all three of our files the same size, the screenshots included. If you want to try it on your own file, make a shortcut with the action, then add a Save File action after it and turn on Show in Share Sheet in the shortcut's details, so you can run it from the Share button in Files.

On iPhone, Mac or anything else: in the browser

SlimIO runs in Safari like any other web page, so the same steps work on iPhone, iPad and Mac:

  1. Open pdfslimio.com and tap the box to choose your PDF. On iPhone you pick it from the Files app.
  2. Leave the defaults (Sharp, Balanced) and tap Compress PDF.
  3. Tap Download compressed PDF. On iPhone the file goes to Files > Downloads.

The two modes differ in where the work happens. Sharp sends the file to our server, where Ghostscript shrinks the images, tidies the fonts and deletes the file as soon as the result comes back; it is the one that made our text report smaller. Private never uploads anything: your phone's browser shrinks the photos inside the PDF and leaves the text alone. If a form wants a specific size, the 1MB, 500KB and 200KB pages keep trying stronger settings until the file fits.

Questions

Why did Preview make my PDF bigger?

Preview's Reduce File Size filter re-saves the whole file, not just the photos. On PDFs that are mostly text it can come out larger: in our test an English report went from 61KB to 122KB, and a Korean one from 101KB to 667KB, because its text was turned into drawn shapes. Keep the original and compare the sizes before you replace anything.

How do I compress a PDF on iPhone?

Apple's built-in route is the Shortcuts action Optimize File Size of PDF, but it did not shrink any of our test files. A browser tool works in Safari: open the page, choose the PDF from Files, compress it and download the result, which lands in Files > Downloads.

Does compressing a PDF lower the quality?

Only the pictures inside change. Photos and scans are stored at a lower resolution and stronger JPEG compression; real text and vector drawings stay sharp with Ghostscript-style compression. At about 150 pixels per inch, scanned text is still easy to read on screen and in print.

How do I get a PDF under 1MB or 500KB?

Use a tool that aims for a size instead of a level, such as SlimIO's 1MB or 500KB pages. It tries stronger settings until the file fits and tells you if it can't.

Is it safe to compress a PDF on a website?

Preview and Shortcuts never send the file anywhere. On SlimIO, the private mode runs in your browser and the file never leaves your device; the default sharp mode sends it to our server, compresses it and deletes it straight away.
