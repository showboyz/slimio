KB, pixels, cm and DPI: photo size rules on application forms, explained

By SlimIO · Updated October 9, 2026 · 4 min read

Application forms describe photos in four different units — centimetres, pixels, DPI and kilobytes — often all in one sentence: "Upload a recent photograph, 3.5 × 4.5 cm, 200 DPI, between 20KB and 50KB, JPG." They measure different things, and a photo can pass one rule while failing another. Here is what each one means and how they fit together.

The four units

UnitWhat it measuresWhat the upload check sees
Pixels (px)The width and height of the image in dots, e.g. 200 × 230Exactly this — portals read the pixel size directly
cm / mm / inchesThe printed size of the photoNothing on its own; it becomes pixels via the DPI
DPI (dots per inch)How many pixels go into one printed inchA conversion factor between cm and pixels
KB (kilobytes)How much storage the file takesThe file size — checked against a minimum and/or maximum

The short version: pixels and KB are what get checked. Centimetres plus DPI are just another way of describing pixels.

Converting cm to pixels

One inch is 2.54 cm. So:

pixels = cm ÷ 2.54 × DPI   (and for millimetres: mm ÷ 25.4 × DPI)

For a 3.5 cm wide photo at 300 DPI: 3.5 ÷ 2.54 × 300 = 413 pixels. Common sizes worked out:

If a form gives centimetres but no DPI, there is no single right pixel size. In practice 200–300 DPI looks good and stays well inside typical KB limits. If the form gives pixels, use the pixels and ignore the centimetres.

Why DPI alone doesn't change anything

A JPEG stores pixels plus a small note saying how many of them to print per inch. Changing that note from 72 to 300 DPI in an editor doesn't add or remove a single pixel, so the file looks identical and its KB stays the same. Portals that ask for "200 DPI" are really asking for enough pixels for the printed size — work out the pixels with the table above.

What decides the KB

For a JPEG, three things set the file size:

  1. Pixel count. 413 × 531 has nearly five times as many pixels as 200 × 230 and usually needs several times the KB.
  2. Detail in the picture. A plain white background and an evenly lit face compress well; a patterned shirt, a busy background or camera noise take more bytes.
  3. JPEG quality. The quality setting trades sharpness for size. Between about 70% and 90% the difference is hard to see but the size can double.

That is why "resize to 200 × 230" doesn't guarantee "under 50KB", and why two people's photos at the same pixel size can differ by 20KB. A good resizer sets the pixels first, then searches for the highest quality that lands inside the KB range.

When the file is too small

Ranges like "20–50KB" or "30–49KB" have a minimum, and simple images — especially signatures on white paper — often come out below it. The options, from best to worst:

  • Raise the JPEG quality. More detail is kept, KB goes up, nothing looks worse.
  • Pad the file. JPEG and PNG files can carry extra data that viewers ignore (a comment block). Adding it raises the KB without touching the picture. SlimIO does this automatically when a result is still under the minimum.
  • Enlarge the pixels. Works, but stretching a small image makes it softer, and it can break a pixel limit.

KB: 1000 or 1024 bytes?

Windows shows file sizes in units of 1024 bytes and calls them KB; macOS, phones and most websites use 1000. The same file of 50,500 bytes shows as 50.5KB on a Mac and 49.3KB on Windows. You can't know which one a portal uses, so stay safely inside the range: for "under 50KB" keep the file under 50,000 bytes, and for "at least 20KB" make it at least 20,480 bytes. SlimIO's limits work this way, so its results pass under either definition.

Shape: crop, don't stretch

3.5 × 4.5 cm is a 7 : 9 shape; 200 × 230 px is a little wider; a phone photo is usually 3 : 4 or 9 : 16. Squeezing one shape into another makes faces look wide or thin, and portals that check face proportions may reject it. Crop to the right shape first — drag the frame onto your face on the ID photo page — and then scale down.

A checklist before you upload

  1. Pixel size matches the form (or the cm converted at 200–300 DPI).
  2. File size is inside the KB range, with a little margin on both ends.
  3. Format is what's asked for — usually JPG/JPEG.
  4. The face or signature fills the frame; the background is plain.

Questions

How many pixels is 3.5 × 4.5 cm?

It depends on the DPI. At 300 DPI it is 413 × 531 pixels; at 200 DPI, 276 × 354; at 100 DPI, 138 × 177. If the form gives pixels, use those numbers — they are what the upload check measures.

Does changing the DPI make my photo bigger or smaller?

No. DPI is only a label inside the file that says how large to print it. Changing it alone doesn't change the pixels or the KB. To change the file size you have to change the pixel dimensions or the compression.

Why does my 20KB file show as 19.9KB?

Two definitions of a kilobyte are in use: 1000 bytes (macOS, most websites) and 1024 bytes (Windows). A 20,400-byte file is 20.4KB on a Mac but 19.9KB on Windows. Aim a little inside the range so the file passes either way.

Can I make a photo bigger in KB without changing it?

Raising JPEG quality increases KB and keeps the picture; enlarging the pixel size adds KB but makes the photo softer. If a small image is still below a minimum, SlimIO adds padding data that viewers ignore, so the file meets the minimum without changing the picture.
