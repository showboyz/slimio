PDF에 페이지 번호 넣는 방법

  • 1. PDF 올리기. 번호를 넣을 파일을 끌어다 놓거나 클릭해서 선택하세요.
  • 2. 모양 고르기. 위치(위·아래, 왼쪽·가운데·오른쪽), 형식, 글자 크기를 고르세요.
  • 3. 다운로드. 페이지 번호 넣기를 누르고 번호가 들어간 PDF를 받으세요.

표지는 번호 없이

보고서나 논문은 보통 표지에 번호를 넣지 않아요. 앞 페이지 건너뛰기를 “1페이지”로 두면 둘째 페이지부터 번호가 들어가요. 시작 번호도 바꿀 수 있어요.

함께 쓰면 좋은 도구

번호를 넣기 전에 순서부터 정리하려면 페이지 순서 변경을, 여러 파일을 먼저 하나로 묶으려면 PDF 합치기를 쓰세요. 검토용 사본이라면 워터마크도 함께 넣을 수 있어요.

PDF 페이지 번호 넣기 — 자주 묻는 질문

PDF에 페이지 번호를 무료로 넣을 수 있나요?

네. 회원가입 없이 하루 20회까지 무료로 쓸 수 있고, 결과 파일에 워터마크도 붙지 않아요.

표지에는 번호를 안 넣을 수 있나요?

네. ‘앞 페이지 건너뛰기’에서 1페이지를 고르면 표지는 비우고 둘째 페이지부터 번호가 들어가요.

번호 형식은 어떤 게 있나요?

1, Page 1, 1 / 10, Page 1 of 10 네 가지 중에서 고를 수 있어요.

가로 페이지나 회전된 페이지에도 제대로 들어가나요?

네. 화면에 보이는 방향을 기준으로 위치를 잡기 때문에 가로 페이지에도 바른 방향으로 들어가요.

파일이 서버로 올라가나요?

아니요. 브라우저 안에서만 처리돼서 파일이 서버로 가지 않아요.
