사진 여러 장을 PDF 하나로: 아이폰·갤럭시에서 만들고 200KB·1MB 용량까지 맞추기

SlimIO 작성 · 업데이트 2026년 10월 16일 · 9 분 분량

서류를 휴대폰으로 찍어 제출하려는데 화면에 "PDF 파일 1개, 최대 1MB" 같은 조건이 붙어 있는 경우가 많아요. 휴대폰 기본 기능으로 사진을 PDF로 묶을 수는 있지만, 사진 한 장이 수 MB라서 PDF도 금방 커지고, 정해진 용량에 맞춰 주는 기능은 없어요. 아이폰·갤럭시·컴퓨터에서 사진 여러 장을 PDF 하나로 만드는 방법을 공식 안내 기준으로 정리하고, 용량을 줄이면 글씨가 어디까지 읽히는지 직접 실험했어요. (2026년 10월 확인)

사진을 PDF 하나로 묶기 →여러 장을 한 번에 올리고 200KB·1MB 같은 용량 제한을 골라요. 사진은 서버로 올라가지 않아요.

제출하는 곳의 안내(파일 형식·용량·장수)가 이 글과 다르면 그쪽이 우선이에요. 휴대폰 메뉴 이름은 기종과 운영체제 버전에 따라 조금 다를 수 있어요. 출처는 글 맨 아래에 있어요.

아이폰에서 사진을 PDF로 만들기

종이 서류를 지금 찍는다면 '문서 스캔'이 가장 깔끔해요. 메모 앱에서 메모를 열고 첨부 파일 버튼 → 문서 스캔을 누른 뒤 서류에 카메라를 대면, 아이폰이 종이 테두리를 찾아 자동으로 찍어요. 여러 장을 이어서 찍고 완료를 누르면 메모 안에 PDF로 저장돼요. iOS 26부터 들어간 미리보기 앱에도 같은 '문서 스캔'이 있어서 바로 PDF를 만들 수 있어요.

이미 찍어 둔 사진이라면 미리보기 앱으로 묶을 수 있지만 단계가 많아요.

  1. 사진 앱에서 사진을 고르고 공유 → 파일에 저장으로 파일 앱에 옮겨요.
  2. 미리보기 앱에서 첫 사진을 열고, 파일 이름 옆 동작 메뉴 → 내보내기 → 포맷을 PDF로 골라 저장해요.
  3. 그 PDF를 열고 페이지 수를 눌러 썸네일을 띄운 뒤, 썸네일을 길게 눌러 파일에서 삽입으로 나머지 사진을 페이지로 넣어요. 썸네일을 길게 눌러 끌면 순서도 바꿀 수 있어요.

미리보기 앱은 PDF를 내보낼 때 '화면에 맞게 이미지 최적화', 'JPEG로 이미지 저장'을 켜서 파일을 작게 만들 수 있어요. 다만 "500KB 이하"처럼 숫자를 정할 수는 없어서, 제출 용량에 맞는지는 저장한 뒤에 확인해야 해요.

사진이 많거나 용량 제한이 있다면 사파리에서 SlimIO 사진→PDF를 여는 게 빨라요. 사진 앱에서 여러 장을 한꺼번에 고르고 용량 제한을 정하면 끝이에요. 내려받은 PDF는 파일 앱의 '다운로드' 폴더에 저장돼요.

갤럭시에서 사진을 PDF로 만들기

여러 장을 묶을 때는 '갤러리 어시스턴트'를 쓰면 돼요. 삼성이 만든 앱으로, 갤럭시 스토어에서 'Gallery Assistant'를 검색해 설치해요(굿락의 '편리한 갤럭시'에서도 설치 가능). 앱에서 PDF로 저장 → 사진 선택 → 저장 순서이고, 페이지 크기(A3·A4·Letter), 세로·가로, 이미지 화질(원본·중간·낮음)을 고를 수 있어요. 삼성 안내 기준으로 One UI 7.0 이상에서 갤럭시 S24 이후 S 시리즈, 폴드7·플립7, A26·A36·A56 등 일부 기기만 지원해요.

앱 설치 없이는 갤러리에서 사진을 열고 더보기(점 3개) → 인쇄 → 프린터 대신 PDF를 골라 저장하는 방법이 있어요. 삼성 멤버스 안내처럼 한 장씩 저장할 때 알맞은 방법이라, 여러 장을 한 파일로 묶기에는 불편해요.

만든 PDF는 사진이 아니라서 갤러리에는 안 보여요. 내 파일 앱에서 찾으세요. 지원 기기가 아니거나 용량 제한이 있다면 크롬·삼성 인터넷에서 SlimIO 사진→PDF를 열고 갤러리 사진을 여러 장 고르면 돼요. 내려받은 PDF는 내 파일 앱의 '다운로드' 폴더에 있어요.

컴퓨터에서는

맥은 Finder에서 사진을 여러 개 선택하고 Control-클릭 → 빠른 동작 → PDF 생성을 고르면 고른 순서대로 PDF 하나가 만들어져요. 윈도우는 사진을 인쇄할 때 프린터를 Microsoft Print to PDF로 고르면 PDF로 저장돼요. 둘 다 용량을 정해 줄이는 기능은 없어요.

휴대폰 사진으로 만든 PDF는 왜 클까

사진을 PDF로 묶는 기능은 대부분 사진을 그대로 PDF 안에 넣어요. 그래서 PDF 용량이 넣은 사진 용량의 합과 거의 같아요. 이번 실험에 쓴 사진은 휴대폰 사진 크기(3024×4032픽셀)로 장당 약 3.8MB였고, 3장을 그대로 묶으니 11.3MB였어요. 제출 화면이 1MB까지만 받는다면 10분의 1 아래로 줄여야 하는 셈이에요.

PDF 용량을 줄이는 방법은 결국 두 가지예요. 사진을 JPG 화질을 낮춰 다시 저장하거나, 픽셀 수(가로·세로 크기)를 줄이는 거예요. 화질을 낮추면 글자 가장자리가 지저분해지고, 픽셀을 줄이면 작은 글씨가 뭉개져요. 그래서 "얼마나 줄여도 읽히는지"가 중요해요.

직접 실험: 용량을 줄이면 글씨는 어디까지 읽힐까

가상 서류 3장(재직증명서·거래명세서·수료증)을 책상 위에서 휴대폰으로 찍은 것처럼 만든 사진(3024×4032픽셀, 장당 약 3.8MB)으로 SlimIO 사진→PDF의 용량 제한을 바꿔 가며 PDF를 만들었어요. SlimIO는 제한에 맞을 때까지 먼저 JPG 화질을 낮추고, 그래도 크면 사진의 픽셀 크기를 줄여요.

정리하면 사진 긴 변이 1,280픽셀 이상이면 작은 글씨까지 읽혔고, 1,024픽셀에서는 작은 글씨가 흐려져 본문 정도만 편하게 읽혔고, 819픽셀에서는 작은 글씨를 읽을 수 없었어요. 이 사진 기준으로는 200KB면 5장, 500KB면 10장 정도가 넉넉한 한계예요. SlimIO는 사진이 1,000픽셀 아래로 줄어들면 결과 화면에서 "작은 글씨는 읽기 어려울 수 있어요"라고 알려 줘요.

다만 사진마다 결과가 달라요. 어두운 곳에서 찍어 자글자글한 점(노이즈)이 많거나 글씨가 빽빽하면 같은 제한에서 더 많이 줄어들어요. 노이즈를 일부러 많이 넣은 다른 예시 사진 3장은 200KB 제한에서 긴 변 655픽셀까지 줄었어요.

같은 용량에서 더 선명하게 만드는 요령

1. 종이만 나오게 찍거나 스캔 기능을 쓰세요. 책상과 그림자까지 나온 사진보다, 종이만 하얗게 나온 스캔본이 같은 용량에서 훨씬 깨끗해요. 흰 배경은 JPG로 아주 작게 저장되기 때문에 그만큼 글씨에 용량을 더 쓸 수 있어요. 아이폰 메모 앱의 '문서 스캔'처럼 종이 테두리를 잘라 주는 기능으로 찍으면 좋아요.

2. 꼭 필요한 장만 넣으세요. 위 표처럼 장수가 늘면 장당 쓸 수 있는 용량이 줄어요. 빈 뒷면, 같은 내용을 두 번 찍은 사진은 빼세요.

3. 밝은 곳에서 찍으세요. 어두우면 노이즈가 생기고, 노이즈는 용량을 많이 차지해요. 그림자가 지지 않게 창가나 조명 아래에서 찍으면 같은 용량에서도 더 선명해요.

4. 제한보다 살짝 여유를 두세요. 사이트마다 1KB를 1,000바이트로 세기도 하고 1,024바이트로 세기도 해요. SlimIO는 1KB를 1,000바이트로 계산해서 어느 쪽으로 세도 통과하게 맞춰요.

5. 파일을 여러 개 올릴 수 있다면 나눠 올리세요. "파일당 1MB, 최대 3개"처럼 개수 제한이 따로 있으면, 한 PDF에 다 넣는 것보다 나눠서 넣는 게 더 선명해요.

이미 만든 PDF가 크다면 PDF 용량 줄이기나 PDF 1MB로 줄이기로 줄일 수 있어요. 아이폰·맥 기본 기능으로 PDF를 줄였을 때의 결과는 아이폰·맥에서 PDF 용량 줄이기에 비교해 뒀어요.

SlimIO로 사진 여러 장을 PDF 하나로

  1. 사진→PDF를 열고 사진을 여러 장 한 번에 고르세요. 휴대폰에서는 앨범에서 바로 고를 수 있어요. 사진은 서버로 올라가지 않고 브라우저 안에서만 처리돼요.
  2. 목록의 ▲ ▼ 버튼으로 페이지 순서를 맞추고, 필요 없는 사진은 ✕로 빼요.
  3. PDF 용량 제한에서 제출 화면에 적힌 숫자를 골라요. 목록에 없으면 '직접 입력'에 KB로 넣어요.
  4. PDF로 변환하기를 누르고 결과 화면에서 PDF 용량과 사진 크기를 확인한 뒤 다운로드해요.

옆으로 저장된 휴대폰 사진도 바로 세워서 넣어요. 사진 한 장이 PDF 한 페이지가 되고, 페이지 크기는 사진 비율 그대로라 여백이 생기지 않아요. 용량 제한을 '제한 없음'으로 두면 사진을 다시 압축하지 않고 원래 화질 그대로 넣어요.

자주 묻는 질문

사진 여러 장을 PDF 하나로 만들려면 어떻게 하나요?

아이폰은 미리보기 앱(iOS 26 이상)에서 PDF에 사진을 페이지로 넣거나, 종이 서류라면 메모 앱의 '문서 스캔'을 쓰면 돼요. 갤럭시는 '갤러리 어시스턴트' 앱의 'PDF로 저장'으로 여러 장을 묶을 수 있어요(One UI 7.0 이상, 지원 기기만). 앱 없이 하려면 브라우저에서 SlimIO 사진→PDF에 여러 장을 한 번에 올리면 돼요.

사진으로 만든 PDF 용량이 너무 커요.

휴대폰 사진은 한 장에 수 MB라서 그대로 묶으면 PDF도 그만큼 커져요. 장당 약 3.8MB인 사진 3장을 그대로 묶으니 11.3MB였어요. 제출 화면에 용량 제한이 있다면 PDF를 만들 때 용량 제한을 고르세요. 같은 사진 3장이 200KB 이하로 들어갔고, 작은 글씨도 읽혔어요.

200KB 제한에 사진 몇 장까지 넣을 수 있나요?

사진에 따라 달라요. 직접 해 보니 서류 사진 3장은 200KB 안에 긴 변 1,600픽셀로 들어가 작은 글씨까지 읽혔고, 5장은 1,280픽셀이었어요. 10장을 넣으면 819픽셀까지 줄어 작은 글씨는 읽을 수 없었어요. 장수가 많으면 제한을 높이거나 꼭 필요한 장만 넣으세요.

휴대폰에서 만든 PDF는 어디에 저장되나요?

아이폰 사파리에서 내려받은 파일은 파일 앱의 '다운로드' 폴더에 저장돼요. 갤럭시는 내 파일 앱의 '다운로드' 폴더에서 찾을 수 있어요. PDF는 사진이 아니라서 사진 앱이나 갤러리에는 보이지 않아요.

PDF 안의 사진 순서를 바꿀 수 있나요?

SlimIO 사진→PDF에서는 변환하기 전에 목록의 ▲ ▼ 버튼으로 순서를 바꿀 수 있어요. 이미 만든 PDF라면 아이폰 미리보기 앱에서 페이지 썸네일을 길게 눌러 끌어 옮기거나, SlimIO의 페이지 정리 도구를 쓰면 돼요.
