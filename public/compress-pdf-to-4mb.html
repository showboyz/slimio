How to compress a PDF to 4MB

  • 1. Add your PDF. The target is already 4MB.
  • 2. Click Compress. At this size SlimIO keeps text as real text and only resamples photos and scans that are bigger than they need to be.
  • 3. Check the result. It shows the new size and whether the text is still selectable.

Where 4MB limits come from

Canada's immigration department (IRCC) caps each uploaded file at 4MB in the IRCC secure account, the Permanent Residence Portal, the online citizenship application and the asylum portal, and at 5MB in the IRCC Portal. Its help centre adds that some applications go as low as 2MB, so check the limit shown next to the upload field before you compress. Every IRCC limit, with the file types each account takes, is in IRCC document upload size limits.

One upload field, several documents

IRCC saves one file per field: upload a second file to the same field and only the last one is kept. Combine the pages first with Merge PDF, then compress the combined file here so the whole set fits.

Why a scan is over 4MB

Phone scanning apps store each page as a full-resolution photo, often 2–4MB per page, so a six-page bank statement can pass 12MB. Those photos are what SlimIO shrinks; the layout stays the same and the pages still read clearly on screen and on paper.

Is the file uploaded?

Briefly, yes. Files up to 50MB go to our server over HTTPS for the text-preserving step and are deleted as soon as they are compressed; nothing is kept. IRCC itself asks applicants to read a tool's privacy policy before using it, so here is ours.

Compress PDF to 4MB — FAQ

How do I make a PDF smaller than 4MB?

Drop it on this page and click Compress. The target is already 4MB; SlimIO keeps text sharp and shrinks only the images as much as needed.

What is the IRCC file size limit?

4MB per file in the IRCC secure account, the Permanent Residence Portal, the online citizenship application and the asylum portal, and 5MB in the IRCC Portal, according to IRCC's help centre (page modified 3 November 2026). Some applications allow only 2MB, so check the upload screen.

Can I upload several files to one IRCC field?

No. Each field keeps one file, the last one you uploaded. Merge the documents into one PDF first, then compress the result to fit.

Will my PDF stay readable at 4MB?

For most documents, yes. 4MB holds many scanned pages at a clear resolution, and documents made on a computer keep their selectable text.

Is my file uploaded?

Files up to 50MB are compressed on our server over HTTPS with a text-preserving method and deleted right after. The image step runs only in your browser.
