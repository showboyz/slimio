지원서를 내는데 업로드 칸은 하나뿐이고, 내야 할 서류는 졸업증명서·성적증명서·자격증 사본 세 개. 이럴 때 PDF 파일 여러 개를 하나로 합쳐야 해요. 😵 학교·회사·관공서 제출에서 정말 자주 나오는 상황이에요.

그래서 아이폰·갤럭시·PC에 들어 있는 기능으로 PDF를 합치는 법을 기기별로 정리하고, 가상 서류 세 개를 실제로 합쳐서 순서와 용량이 어떻게 되는지까지 확인했어요. 📝

⏱ 3줄 요약
1️⃣ 아이폰은 미리보기 앱 '파일에서 삽입', 맥은 Finder 'PDF 생성', 윈도우는 아직 기본 기능이 없어요
2️⃣ 합칠 때 가장 중요한 건 순서예요. 공고문에 적힌 서류 순서대로 맞추세요
3️⃣ 합친 용량은 더한 값과 비슷해요. 제한을 넘으면 합친 뒤에 한 번 줄이면 돼요

📋 기기별 방법 한눈에 보기

기기방법알아 둘 점
아이폰미리보기 앱 → 썸네일 길게 누르기 → 파일에서 삽입iOS 26 이상, 연 파일에 바로 저장
갤럭시삼성 노트 편집 → 첨부(클립) → PDF마지막에 PDF로 다시 저장
맥Finder에서 여러 개 선택 → 빠른 동작 → PDF 생성고른 순서대로 합쳐짐
윈도우기본 기능 없음웹 도구나 프로그램 필요
모든 기기브라우저 합치기 도구순서 바꾸기 버튼, 설치 없음

🍎 아이폰: 미리보기 앱에 다른 PDF 끼워 넣기

iOS 26부터 생긴 미리보기 앱에서 맨 앞에 올 PDF를 열어요. 썸네일 보기 버튼을 눌러 페이지 목록을 띄운 다음, 썸네일 하나를 길게 누르면 메뉴가 나와요. 여기서 파일에서 삽입을 누르고 붙일 PDF를 고르면 그 파일의 페이지가 들어와요. 사진 파일도 같은 방법으로 넣을 수 있어요.

들어간 자리가 마음에 안 들면 그 썸네일을 꾹 눌러 메뉴가 나오면, 손을 떼지 말고 위아래로 끌어 옮기면 돼요. 다만 미리보기는 처음 연 파일 자체를 고쳐서 저장하니, 원래 파일을 그대로 남기고 싶다면 시작 전에 복제해 두세요.

💡 파일 앱에서 여러 개를 고른 뒤 더 보기(⋯) → 'PDF 생성'으로 한 번에 묶는 방법도 있어요. 다만 Apple 설명서에 이 메뉴의 순서 규칙이 나와 있지 않아서, 순서가 중요한 제출 서류라면 합친 뒤 꼭 열어서 확인하거나 위의 미리보기 방법을 쓰세요.

📱 갤럭시: 삼성 노트에 PDF 붙이기

갤럭시에는 PDF 합치기 버튼이 따로 없어요. 대신 삼성 멤버스 커뮤니티에서 삼성노트 담당자가 안내한 방법이 있어요. 첫 번째 PDF를 삼성 노트로 연 뒤 편집 모드에서 첨부(클립 모양) → PDF를 누르고 이어 붙일 파일을 고르면 같은 노트에 추가돼요.

다 붙였으면 더 보기(⋮) → 파일로 저장 → PDF 파일로 저장해야 제출할 수 있는 PDF가 생겨요. 노트 스타일과 앱 버전에 따라 메뉴 위치가 조금 다를 수 있어요. 메뉴를 못 찾겠다면 아래 브라우저 도구가 더 빨라요.

💻 PC: 맥은 Finder, 윈도우는 도구 필요

맥은 Finder에서 합칠 파일을 골라 Control-클릭 → 빠른 동작 → PDF 생성을 누르면 끝이에요. Apple 설명서에 따르면 고른 순서대로 합쳐지니, 첫 번째 서류부터 차례로 Command-클릭하세요. 미리보기 앱에서 보기 → 썸네일을 켜고 한 PDF의 썸네일을 다른 PDF 사이드바로 끌어 놓는 방법도 있어요.

윈도우에는 PDF를 합치는 기본 기능이 없어요. 엣지로 PDF를 열어도 합치기 메뉴는 없어요. PDF 프로그램을 설치해도 되지만, 가끔 합칠 거라면 브라우저 도구가 간단해요.

🔬 직접 합쳐 봤어요: 서류 3개 → 1개

가상의 예시대학교 졸업증명서(1쪽), 성적증명서(2쪽), 휴대폰으로 스캔한 것 같은 자격증 사본(1쪽)을 준비했어요. 실제로 자주 하는 실수처럼 자격증 사본을 먼저 올린 다음, 순서를 바로잡아 합쳤어요.

항목합치기 전합친 뒤
파일 수3개1개
쪽수1 + 2 + 1쪽4쪽
용량121 + 99 + 617 = 837KB720KB

결과에서 알게 된 세 가지예요.

  • 📏 용량은 거의 더한 값이에요. 이번엔 14% 정도 작아졌는데, 스캔 사진 데이터는 원본과 바이트 수까지 같았어요. 화질을 낮춘 게 아니라 파일을 새로 저장하면서 내부 구조가 정리된 정도예요. 그러니 합치면 용량이 확 줄 거라고 기대하면 안 돼요.
  • 📦 무거운 건 스캔본이에요. 글자로 된 증명서 두 개를 합쳐도 220KB인데, 사진으로 찍은 사본 한 장이 617KB였어요. 용량 제한에 걸리면 스캔본부터 줄이세요.
  • 🔤 글자는 그대로예요. 합친 파일에서도 증명서 글자를 드래그해 복사할 수 있었어요.

✂️ SlimIO로 순서 맞춰 합치기

위 실험은 제가 직접 만들어 운영하는 무료 도구 SlimIO로 했어요. 회원가입 없이 쓰고, 합치기는 브라우저 안에서만 처리돼서 증명서가 서버로 올라가지 않아요. 🙌

1️⃣ PDF 합치기 (SlimIO)를 열고 합칠 PDF를 한꺼번에 고르세요. 휴대폰에서도 돼요.
2️⃣ 목록에서 ▲ ▼로 순서를 맞추고, 잘못 넣은 파일은 ✕로 빼세요. 실험에서는 자격증 사본의 ▼를 두 번 눌렀어요.
3️⃣ PDF 합치기를 누르면 합친 파일 수·전체 쪽수·용량이 나오고, 바로 내려받을 수 있어요. ✅

내려받은 파일 이름은 slimio_merged.pdf예요. 제출하기 전에 '홍길동_지원서류.pdf'처럼 이름을 바꿔 두면 받는 쪽에서도 알아보기 쉬워요.

✅ 제출 전에 꼭 확인할 것

  • 📑 순서: 공고문에 '지원서 → 졸업증명서 → 성적증명서'처럼 순서가 있으면 그대로 맞추세요. 없으면 지원서·신청서를 맨 앞에 두는 게 무난해요.
  • 📦 용량: 합친 파일이 제한보다 크면 PDF 1MB로 줄이기처럼 목표 용량에 맞춰 줄이세요. 메일로 보낼 거라면 메일 첨부용 PDF 줄이기도 있어요.
  • 🔐 암호 걸린 PDF: 열 때 암호를 묻는 파일은 합칠 수 없어요. 암호를 푼 파일로 다시 해 보세요.
  • 🔏 전자서명된 PDF: 전자서명은 '서명한 뒤 파일이 바뀌지 않았다'를 보증하는 장치예요. 다른 파일과 합치면 서명이 빠지거나 확인할 수 없는 상태가 될 수 있어요. 겉으로 서명 그림이 보여도 마찬가지예요. 이런 파일은 따로 내도 되는지 제출처에 먼저 물어보세요.
  • 📄 원본 그대로 요구: '발급받은 PDF를 그대로 올리라'는 안내가 있으면 합치지 말고 칸마다 따로 올리세요.

사진 여러 장을 PDF 하나로 묶는 건 사진 여러 장 PDF 하나로 합치는 법에, 합친 PDF에서 빈 쪽을 빼거나 순서를 손보는 건 이 블로그의 'PDF 페이지 삭제·회전·한 페이지만 저장' 글에 정리해 두었어요. 서류 제출 한 번에 끝내세요! 💌
