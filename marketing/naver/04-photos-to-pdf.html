서류를 휴대폰으로 찍어서 내려는데 "PDF 파일 1개, 최대 1MB" 같은 조건이 붙어 있으면 막막하죠? 😥

휴대폰 기본 기능으로 사진을 PDF로 묶을 수는 있지만, 사진 한 장이 몇 MB라서 PDF도 금방 커지고 정해진 용량에 맞춰 주는 기능은 없어요. 그래서 아이폰·갤럭시·컴퓨터에서 사진 여러 장을 PDF 하나로 만드는 법을 공식 안내 기준으로 정리하고, 용량을 줄이면 글씨가 어디까지 읽히는지 직접 실험해 봤어요. 📝

⏱ 3줄 요약
1️⃣ 종이 서류를 지금 찍는다면 아이폰 메모 앱의 '문서 스캔'이 가장 깔끔해요
2️⃣ 휴대폰 기본 기능은 KB 숫자를 정해서 줄이지 못해요
3️⃣ 실험해 보니 서류 사진 3장은 200KB까지 작은 글씨가 읽혔어요

🍎 아이폰에서 사진을 PDF로

종이 서류를 지금 찍는다면 '문서 스캔'이 가장 깔끔해요. 메모 앱에서 메모를 열고 첨부 파일 버튼 → 문서 스캔을 누른 뒤 서류에 카메라를 대면, 아이폰이 종이 테두리를 찾아 자동으로 찍어요. 여러 장을 이어서 찍고 완료를 누르면 메모 안에 PDF로 저장돼요. iOS 26부터 들어간 미리보기 앱에도 같은 '문서 스캔'이 있어요.

이미 찍어 둔 사진이라면 미리보기 앱으로 묶을 수 있지만 단계가 많아요.

  • 사진 앱에서 사진을 고르고 공유 → 파일에 저장으로 파일 앱에 옮겨요.
  • 미리보기 앱에서 첫 사진을 열고, 파일 이름 옆 동작 메뉴 → 내보내기 → 포맷을 PDF로 골라 저장해요.
  • 그 PDF를 열고 페이지 수를 눌러 썸네일을 띄운 뒤, 썸네일을 길게 눌러 '파일에서 삽입'으로 나머지 사진을 넣어요. 길게 눌러 끌면 순서도 바뀌어요.

미리보기 앱은 PDF를 내보낼 때 '화면에 맞게 이미지 최적화', 'JPEG로 이미지 저장'을 켜서 작게 만들 수 있어요. 다만 "500KB 이하"처럼 숫자를 정할 수는 없어서, 저장한 뒤에 용량을 확인해야 해요.

📱 갤럭시에서 사진을 PDF로

여러 장을 묶을 때는 삼성이 만든 '갤러리 어시스턴트'를 쓰면 돼요. 갤럭시 스토어에서 'Gallery Assistant'를 검색해 설치하고(굿락의 '편리한 갤럭시'에서도 설치 가능), PDF로 저장 → 사진 선택 → 저장 순서로 하면 돼요. 페이지 크기(A3·A4·Letter), 세로·가로, 이미지 화질(원본·중간·낮음)을 고를 수 있어요. 삼성 안내 기준으로 One UI 7.0 이상에서 갤럭시 S24 이후 S 시리즈, 폴드7·플립7, A26·A36·A56 등 일부 기기만 지원해요.

앱 설치 없이는 갤러리에서 사진을 열고 더보기(점 3개) → 인쇄 → 프린터 대신 PDF를 골라 저장하는 방법이 있어요. 한 장씩 저장할 때 알맞은 방법이라 여러 장을 묶기에는 불편해요. 만든 PDF는 사진이 아니라서 갤러리에는 안 보이고, 내 파일 앱에서 찾아야 해요.

💻 컴퓨터에서는

맥은 Finder에서 사진을 여러 개 선택하고 Control-클릭 → 빠른 동작 → PDF 생성을 고르면 고른 순서대로 PDF 하나가 만들어져요. 윈도우는 사진을 인쇄할 때 프린터를 Microsoft Print to PDF로 고르면 PDF로 저장돼요. 둘 다 용량을 정해 줄이는 기능은 없어요.

🤔 휴대폰 사진 PDF는 왜 이렇게 클까

사진을 PDF로 묶는 기능은 대부분 사진을 그대로 PDF 안에 넣어요. 그래서 PDF 용량이 사진 용량의 합과 거의 같아요. 이번 실험 사진은 장당 약 3.8MB(3024×4032픽셀)였고, 3장을 그대로 묶으니 11.3MB였어요. 1MB 제한이면 10분의 1 아래로 줄여야 하는 셈이에요.

줄이는 방법은 결국 두 가지예요. JPG 화질을 낮추거나, 픽셀 수(가로·세로 크기)를 줄이는 거예요. 화질을 낮추면 글자 가장자리가 지저분해지고, 픽셀을 줄이면 작은 글씨가 뭉개져요. 그래서 "얼마나 줄여도 읽히는지"가 중요해요.

🔬 직접 실험: 글씨는 어디까지 읽힐까

가상 서류 3장(재직증명서·거래명세서·수료증)을 휴대폰으로 찍은 것처럼 만든 사진으로, SlimIO 사진→PDF의 용량 제한을 바꿔 가며 PDF를 만들었어요.

제한 없음11.3MB4032px선명

재직증명서 맨 아래의 작은 글씨를 같은 배율로 확대해서 비교해 봤어요.

사진 긴 변이 1,280픽셀 이상이면 작은 글씨까지 읽혔고, 1,024픽셀에서는 작은 글씨가 흐려졌고, 819픽셀(200KB에 10장)에서는 작은 글씨를 읽을 수 없었어요. 이 사진 기준으로는 200KB면 5장, 500KB면 10장 정도가 넉넉한 한계예요. 다만 어두운 곳에서 찍어 자글자글한 점(노이즈)이 많거나 글씨가 빽빽하면 같은 제한에서 더 많이 줄어들어요.

💡 같은 용량에서 더 선명하게 만드는 요령

1. 종이만 나오게 찍거나 스캔 기능을 쓰세요. 책상과 그림자까지 나온 사진보다, 종이만 하얗게 나온 스캔본이 같은 용량에서 훨씬 깨끗해요. 흰 배경은 아주 작게 저장돼서 그만큼 글씨에 용량을 더 쓸 수 있어요.

둘 다 3장을 100KB 이하로 만든 결과예요. 종이만 나온 스캔본 쪽이 작은 글씨가 또렷해요.

2. 꼭 필요한 장만 넣으세요. 장수가 늘면 장당 쓸 수 있는 용량이 줄어요. 빈 뒷면, 같은 내용을 두 번 찍은 사진은 빼세요.
3. 밝은 곳에서 찍으세요. 어두우면 노이즈가 생기고, 노이즈는 용량을 많이 차지해요.
4. 제한보다 살짝 여유를 두세요. 사이트마다 1KB를 1,000바이트로 세기도 하고 1,024바이트로 세기도 해요.
5. 여러 파일을 올릴 수 있다면 나눠 올리세요. "파일당 1MB, 최대 3개"처럼 개수 제한이 따로 있으면 나눠 넣는 게 더 선명해요.

✂️ SlimIO로 사진 여러 장을 PDF 하나로

제가 직접 만들어 운영하는 무료 도구 SlimIO로 하면 용량까지 한 번에 맞출 수 있어요. 회원가입 없이 쓰고, 사진이 서버로 올라가지 않고 브라우저 안에서만 처리돼요. 🙌

1️⃣ 사진→PDF (SlimIO)를 열고 사진을 여러 장 한 번에 고르세요. 휴대폰에서는 앨범에서 바로 고를 수 있어요.
2️⃣ ▲ ▼ 버튼으로 페이지 순서를 맞추고, 필요 없는 사진은 ✕로 빼요.
3️⃣ 'PDF 용량 제한'에서 제출 화면에 적힌 숫자를 골라요. 목록에 없으면 '직접 입력'에 KB로 넣어요.
4️⃣ PDF로 변환하기 → 결과 화면에서 용량과 사진 크기를 확인하고 다운로드! ✅

옆으로 저장된 휴대폰 사진도 바로 세워서 넣고, 사진 한 장이 PDF 한 페이지가 돼요. 사진이 1,000픽셀 아래로 줄어들면 결과 화면에서 "작은 글씨는 읽기 어려울 수 있어요"라고 알려 줘요. 내려받은 PDF는 아이폰은 파일 앱, 갤럭시는 내 파일 앱의 '다운로드' 폴더에 있어요.

장수별 실험 결과까지는 사진 여러 장 PDF 만들기 가이드에 더 자세히 정리해 두었어요. 서류 제출 잘 마무리하세요! 🍀
