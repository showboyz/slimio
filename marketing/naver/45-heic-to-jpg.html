아이폰으로 찍은 증명사진이나 서류 사진을 컴퓨터로 옮겼는데, 파일 이름 끝이 .HEIC로 되어 있어서 당황한 적 있으세요? 원서 접수나 관공서 사이트에 올리려고 하면 "JPG, PNG 파일만 올릴 수 있어요"라는 안내에 막히곤 하죠. 😥

그래서 Apple 공식 지원 문서로 HEIC가 무엇이고 어떻게 JPG로 바꾸는지 확인하고, 실험용 HEIC 사진 3장을 실제로 JPG로 바꿔 용량까지 재 봤어요. 📝

⏱ 3줄 요약
1️⃣ 앞으로 찍을 사진은 설정 → 카메라 → 포맷 → '높은 호환성'으로 바꾸면 JPEG로 저장돼요
2️⃣ 이미 찍은 HEIC는 미리보기 앱의 '내보내기'(아이폰·맥)로 바꾸거나, 브라우저 변환 도구로 여러 장을 한 번에 바꿀 수 있어요
3️⃣ JPG는 HEIC보다 용량이 커지는 편이라, 원서용이면 용량 제한도 같이 거세요 (실험: 2.86MB HEIC → 200KB 이하 189.3KB)

🤔 HEIC가 뭐예요?

Apple 안내에 따르면 HEIF는 High Efficiency Image File Format, 말 그대로 공간을 아끼는 고효율 사진 포맷이에요. iPhone 7 이후 기종(iOS 11 이후)은 카메라 포맷이 '고효율성'으로 되어 있으면 사진을 이 포맷으로 저장해요. 우리가 보는 파일 이름 끝의 .HEIC가 바로 이 사진이에요.

아이폰 안에서 볼 때는 별문제가 없어요. 문제는 파일 그대로 컴퓨터로 옮겨서 업로드할 때예요. 원서·채용·민원 사이트 중에는 JPG·PNG만 받는 곳이 많아서, HEIC 파일은 고를 수조차 없거나 "형식이 맞지 않는다"며 거절돼요.

📱 앞으로 찍을 사진은 JPG로 (설정 한 번)

Apple이 안내하는 방법은 간단해요. 설정 → 카메라 → 포맷으로 들어가서 '높은 호환성'을 누르면, 그다음부터 찍는 사진과 동영상은 JPEG·H.264로 저장돼요.

포맷 설정저장 형식특징
고효율성HEIF·HEVC저장 공간 절약
높은 호환성JPEG·H.264어디서나 열기 쉬움

두 가지만 기억하세요. 이 설정은 새로 찍는 사진부터 적용돼서 이미 찍은 HEIC는 그대로 남아요. 그리고 HEIF로 찍을 수 있는 iPhone·iPad에만 이 메뉴가 있어요. 저장 공간이 넉넉하지 않다면 평소엔 '고효율성'으로 두고, 원서용 사진을 찍을 때만 바꾸는 방법도 있어요.

🔄 공유하거나 PC로 옮길 때 저절로 바뀌기도 해요

Apple 안내에는 이런 내용도 있어요. 사진을 받는 기기가 최신 포맷을 지원하지 않으면, 공유할 때 JPEG 같은 호환 포맷으로 자동으로 바뀌어 보내질 수 있어요. 케이블로 연결해 PC나 Mac의 사진 앱으로 가져올 때도 JPEG로 바뀔 수 있고요.

반대로 설정 → 앱 → 사진 아래쪽에서 '원본 유지'를 골라 두면 HEIC 그대로 옮겨져요. 컴퓨터에 HEIC 파일이 계속 쌓인다면, 이 설정이 켜져 있지 않은지 먼저 확인해 보세요.

💻 이미 찍은 HEIC를 JPG로 바꾸는 법

  • 🍎 Mac: 미리보기 앱에서 사진을 열고 파일 → 내보내기 → 포맷 팝업 메뉴에서 JPEG → 저장. 여러 장이면 한 윈도우에 모두 열고, 사이드바에서 사진들을 선택한 다음 같은 순서로 내보내면 돼요 (Apple 미리보기 사용 설명서).
  • 📱 아이폰에서 바로: iOS 26부터 있는 미리보기 앱에서 사진을 열고, 파일 이름 옆 동작 메뉴 → 내보내기에서 JPEG를 고르면 돼요 (Apple iPhone 사용 설명서). 한 장씩 할 때 편해요.
  • 🖥️ 윈도우 PC·여러 장: 프로그램을 설치하기 어렵다면 브라우저에서 바로 바꾸는 방법이 편해요. 아래에서 제가 만든 무료 도구로 직접 해 봤어요.

🔁 여러 장을 한 번에: 직접 해 봤어요

실험용으로 얼굴이 나오지 않는 사진 3장(책상 위 가상 '졸업증명서(예시)', 바다, 꽃밭)을 만들어 HEIC로 저장했어요. 크기는 모두 4032×3024, 용량은 2.86MB·3.20MB·3.22MB(합계 9.28MB)예요. 설정을 바꿔 가며 JPG로 바꾼 결과는 이래요.

화질·크기·용량결과 크기JPG 용량
92%·원래 크기4032×30242.86MB → 3.16MB
92%·1MB 이하4032×3024912~975KB
85%·2048px·1MB2048×1536280~490KB (3장 1.04MB)
92%·200KB 이하2393×17952.86MB → 189.3KB

눈여겨볼 건 첫 줄이에요. HEIC가 압축을 더 잘해서, 그대로 JPG로 바꾸면 오히려 3.16MB로 커졌어요. 원서 사이트에 용량 제한이 있다면 '용량 제한'을 같이 고르는 게 좋아요. 200KB 이하로 줄인 서류 사진도 확대해 보니 이름·날짜 글씨가 또렷하게 읽혔어요. 3장을 한꺼번에 넣었을 때는 사진마다 JPG가 생기고, 전체를 ZIP 하나로도 받을 수 있었어요.

  • 🔁 바꾸는 곳: SlimIO HEIC JPG 변환 — 회원가입 없이 무료이고, 사진은 브라우저 안에서만 바뀌어서 서버로 올라가지 않아요. 처음 한 번만 변환 도구를 불러오느라 몇 초 더 걸려요.
  • 🪪 원서 증명사진이라면: HEIC 그대로 SlimIO 증명사진 크기 맞추기에 넣으면 돼요. 이제 SlimIO의 사진 도구(증명사진, 사진 용량 줄이기, 서명 이미지, JPG→PDF)는 모두 HEIC를 바로 열어요.
  • 📏 20~50KB처럼 범위가 정해져 있다면: SlimIO 사진 용량 줄이기에서 범위를 직접 넣으세요. 용량 맞추는 요령은 사진 용량 50KB·100KB 맞추는 법에 정리해 두었어요.

💡 바꾼 JPG에는 촬영 날짜나 위치 같은 카메라 정보가 담기지 않아요. 업로드용으로는 오히려 깔끔하지만, 날짜 기록이 필요하면 원본 HEIC도 함께 보관해 두세요.

✅ HEIC 업로드 체크리스트

  • ☑️ 파일 이름 끝이 .HEIC인지 확인
  • ☑️ 앞으로 찍을 사진: 설정 → 카메라 → 포맷 → 높은 호환성
  • ☑️ PC로 옮길 때 HEIC가 계속 생기면 사진 설정의 '원본 유지' 확인
  • ☑️ 이미 찍은 사진: 미리보기 '내보내기'(아이폰·맥) 또는 브라우저 변환
  • ☑️ 원서용이면 용량 제한(예: 200KB 이하)까지 같이
  • ☑️ 증명사진 규격이 있으면 증명사진 도구에 HEIC 그대로
