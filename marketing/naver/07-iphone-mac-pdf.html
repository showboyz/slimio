휴대폰으로 서류를 찍어서 PDF로 만들었더니 몇 MB가 돼서 제출 사이트에 안 올라간 적 있으시죠? 😥 한 장 한 장이 1,200만 화소 사진이라 그래요.

애플 기기에는 PDF 용량을 줄이는 기본 기능이 두 가지 있어요. 맥의 미리보기와 아이폰의 단축어예요. 같은 파일로 두 기능과 브라우저 도구를 직접 비교해 봤어요. 📝

⏱ 3줄 요약
1️⃣ 아이폰 단축어 'PDF 파일 크기 최적화'는 시험한 파일 모두 크기가 그대로였어요
2️⃣ 맥 미리보기 '파일 크기 줄이기'는 사진 PDF는 줄지만, 글자 PDF는 6.6배로 커졌어요
3️⃣ 브라우저 도구는 사진 PDF를 95% 줄였고 글자 PDF도 줄었어요

🧪 시험한 파일 3개

  • 📄 종이 서류를 찍은 사진: 3쪽짜리 임대차 계약서를 휴대폰으로 찍은 것처럼 만든 사진(쪽마다 3024×4032)을 PDF 하나로 묶은 파일, 7.1MB. "PDF 용량이 너무 커요"의 대부분이 이런 파일이에요.
  • 📱 화면 캡처: 휴대폰 화면 캡처 3장을 PDF로 저장한 파일, 655KB
  • 📝 글자 위주 보고서: 글·제목·표·그래프가 있는 4쪽 보고서를 브라우저에서 PDF로 저장한 파일, 101KB

💡 용량은 파인더·파일 앱 기준(1KB = 1,000바이트)이에요. 가장 눈에 띈 건 미리보기로 줄인 글자 보고서예요. 용량이 6.6배로 커졌을 뿐 아니라, 한글 글자가 모두 선으로 그린 모양으로 바뀌어서 글자를 복사하거나 검색할 수 없게 됐어요. (단축어의 서류 사진 칸은 같은 구성의 영어 서류로 시험했어요.)

서류 사진 PDF 1쪽을 같은 배율로 확대해서 비교해 봤어요.

미리보기 결과는 글자 둘레에 네모난 압축 자국이 살짝 보여요. SlimIO 균형은 그 3분의 1 용량인데도 비슷하게 선명해요. SlimIO 최소 용량(111KB)은 흐려지지만 읽을 수는 있어요.

💻 맥: 미리보기 '파일 크기 줄이기'

애플이 안내하는 맥 방법이에요. 미리보기 앱으로 PDF를 열고 → 파일 > 내보내기('PDF로 내보내기'가 아니에요) → Quartz 필터에서 파일 크기 줄이기 → 원본이 남도록 이름을 바꿔 저장하면 돼요.

macOS 27의 이 필터 설정 파일을 열어 보면, 이미지를 1인치당 144픽셀, 긴 변 최대 2,400픽셀, JPEG 품질 0.7로 저장하라고 되어 있어요. 그래서 사진 PDF는 꽤 줄어요. 문제는 사진만이 아니라 파일 전체를 다시 쓴다는 점이에요. 글자 PDF에서는 위처럼 오히려 나빠졌어요. 꼭 원본과 용량을 비교한 뒤에 원본을 지우세요.

📱 아이폰·아이패드: 단축어 'PDF 파일 크기 최적화'

아이폰의 기본 방법은 단축어 앱의 'PDF 파일 크기 최적화' 동작이에요. 애플이 붙인 설명부터 조심스러워요. "PDF에 포함된 이미지가 이미 압축된 경우 이 작업은 파일 크기에 별다른 영향을 미치지 않을 수 있습니다."

실제로도 그랬어요. 휴대폰 사진은 이미 JPEG로 압축돼 있어서 그런지, 화면 캡처까지 세 파일 모두 크기가 그대로였어요. 그래도 내 파일로 시험해 보고 싶다면 새 단축어에 'PDF 파일 크기 최적화'와 '파일 저장' 동작을 넣고, 단축어 세부사항에서 '공유 시트에서 보기'를 켜면 파일 앱의 공유 버튼에서 바로 실행할 수 있어요.

🌐 아이폰·맥 어디서나: 브라우저에서 줄이기

제가 직접 만들어 운영하는 무료 도구 SlimIO는 사파리에서 열리는 웹페이지라서 아이폰, 아이패드, 맥에서 방법이 같아요. 회원가입 없이 쓸 수 있어요. 🙌

1️⃣ SlimIO PDF 압축을 열고 상자를 눌러 PDF를 골라요. 아이폰에서는 파일 앱에서 고르면 돼요.
2️⃣ 기본값(선명하게, 균형) 그대로 PDF 압축하기를 눌러요.
3️⃣ 압축된 PDF 다운로드를 누르면 아이폰에서는 파일 앱의 '다운로드' 폴더에 저장돼요. ✅

서류 사진 PDF를 휴대폰에서 줄인 화면이에요.

SlimIO 화면은 1KB를 1,024바이트로 계산해서 6.81MB → 359KB로 보여요. 파일 앱과 파인더에서는 같은 파일이 7.1MB → 368KB로 보여요.

두 방식은 처리하는 곳이 달라요. 선명하게는 파일을 서버로 보내 사진을 줄이고 글꼴을 정리한 뒤, 결과를 돌려주자마자 파일을 지워요. 글자 보고서까지 줄어든 건 이 방식이에요. 기기 안에서만은 아무것도 올리지 않고, 휴대폰 브라우저가 PDF 속 사진만 줄여요.

🙋 내 PDF에는 뭘 쓸까

  • 📄 종이 서류를 찍거나 스캔한 PDF: 어떤 방법이든 많이 줄어요. 미리보기는 약 6.5배, SlimIO 균형은 약 19배 작아졌어요.
  • 📱 화면 캡처 PDF: 줄어드는 폭이 작아요. SlimIO '기기 안에서만'이 3분의 2쯤 줄였어요.
  • 📝 글자 위주 PDF(한글·워드·브라우저에서 저장): 원래 작은 편이에요. 미리보기 필터는 쓰지 마세요.
  • 🎯 1MB처럼 용량 제한에 맞춰야 할 때: 용량별 페이지(1MB·500KB·200KB)를 쓰면 맞을 때까지 설정을 바꿔 가며 줄여 줘요.

그래도 크다면 설정보다 쪽수가 효과가 커요. 제출처가 요구하는 쪽만 남기거나, 밝은 곳에서 다시 찍어 보세요. 시험 과정은 아이폰·맥 PDF 용량 줄이기 가이드에 더 자세히 있어요. 📎
