휴대폰이나 스캐너로 서류를 PDF로 만들면 꼭 하나씩 말썽이에요. 😩 빈 뒷면이 끼어 있고, 가로 표는 옆으로 누워 있고, 순서는 뒤죽박죽이죠. 반대로 증명서 여러 쪽 중 딱 한 쪽만 내야 할 때도 있고요.

유료 프로그램 없이 휴대폰과 PC에 들어 있는 기능으로 PDF를 정리하는 법을 기기별로 모았어요. 실제 스캔본 같은 가상 서류로 직접 정리해 본 결과도 같이 보여 드릴게요. 📝

⏱ 3줄 요약
1️⃣ 아이폰은 미리보기 앱(iOS 26 이상), 갤럭시는 삼성 노트 '페이지 관리', PC는 인쇄 → PDF로 저장 + 페이지 범위
2️⃣ 고치기 전에 원본 복사본부터 만들어 두세요 (바로 저장되는 앱이 많아요)
3️⃣ 빈 페이지만 빼도 용량이 줄어요. 실험에서는 5쪽 → 4쪽, 17% 감소

🍎 아이폰: 미리보기 앱

iOS 26부터 들어간 미리보기 앱에서 PDF를 열고, 쪽수 표시를 누르면 페이지 썸네일이 나와요(iOS 27은 '사이드바 보기' 버튼). 여기서 하면 돼요.

  • 🗑 삭제: 썸네일을 길게 누르고 '페이지 삭제'
  • ↻ 회전: 더 보기 → '왼쪽으로 회전' 또는 '오른쪽으로 회전'
  • ⇄ 순서: 썸네일을 메뉴가 뜰 때까지 길게 누른 뒤 원하는 자리로 끌기
  • ↩ 되돌리기: 더 보기 → 실행 취소

다 했으면 뒤로 버튼을 누르면 같은 파일에 저장돼요. 그래서 원본을 남기고 싶다면 시작하기 전에 파일 이름 옆 동작 메뉴에서 복제부터 하세요. 한 쪽만 저장하고 싶을 때도 복제한 파일에서 나머지 페이지를 지우면 돼요.

📱 갤럭시: 삼성 노트 '페이지 관리'

내 파일에서 PDF를 누르고 연결 프로그램으로 Samsung Notes를 고르면 PDF가 열려요. 여기서 페이지 관리로 들어가면 페이지를 추가·복사·잘라 넣기·삭제할 수 있고(삼성 노트 4.4.09.4 버전부터), 페이지를 길게 눌러 끌면 순서도 바뀌어요. 다 했으면 더 보기(⋮) → 파일로 저장 → PDF 파일로 저장하세요. 삼성 노트로 가져온 PDF는 복사본이라 원래 파일은 그대로 남아요.

삼성 노트 공식 안내에서 페이지 회전 방법은 찾지 못했어요. 옆으로 누운 쪽은 아래 브라우저 도구로 돌리는 게 확실해요.

💻 PC: 인쇄 범위와 맥 미리보기

윈도우는 PDF를 엣지로 열고 인쇄를 누른 뒤, 프린터를 'Microsoft Print to PDF'(또는 PDF로 저장)로 바꾸고 페이지 → 사용자 지정에 '3'이나 '1-5', '3, 6, 8'처럼 적으면 그 쪽만 새 PDF로 저장돼요. 필요한 쪽만 떼어 낼 때 가장 쉬운 방법이에요.

맥은 미리보기에서 보기 → 썸네일을 켜고, 썸네일을 골라 Delete 키로 지우거나 끌어서 순서를 바꾸고, 회전 버튼으로 돌려요. 썸네일 하나를 데스크탑으로 끌어다 놓으면 그 쪽만 새 PDF가 돼요. 미리보기는 바뀐 내용을 자동으로 저장하니 원본은 미리 복사해 두세요.

🔬 직접 해 봤어요: 스캔본 정리

휴대폰으로 스캔한 것 같은 가상 '동아리 활동 보고서' 5쪽을 준비했어요. 2쪽 예산 표는 옆으로 누웠고, 4쪽은 빈 뒷면이고, 예산이 활동 내역보다 앞에 있어요. 제가 직접 만들어 운영하는 무료 도구 SlimIO의 '페이지 순서 변경'에서 버튼 세 번으로 정리했어요.

1️⃣ PDF 페이지 순서 변경 (SlimIO)을 열고 PDF를 올리면 모든 페이지가 미리보기로 나와요.
2️⃣ 누운 쪽은 ↻(누를 때마다 시계 방향 90°), 빈 쪽은 ✕, 순서는 ← →로 옮겨요. 컴퓨터에서는 끌어다 놓아도 돼요.
3️⃣ PDF 저장하기를 누르면 새 파일로 받아져요. 원본은 그대로예요. ✅

결과는 5쪽 1.43MB → 4쪽 1.18MB. 스캔본은 빈 쪽도 종이 질감까지 그림으로 담겨 있어서, 빈 쪽 하나만 빼도 용량이 17% 줄었어요. 돌리고 옮기는 건 페이지를 다시 그리지 않아서 화질과 글자가 그대로예요. 회원가입 없이 쓰고, 파일은 서버로 올라가지 않고 브라우저 안에서만 처리돼요. 🙌

한 쪽만 저장하고 싶다면 PDF 나누기에서 '원하는 페이지만 뽑아 PDF 하나로'를 고르고 '3'이나 '1-3, 5'처럼 적으면 돼요. 빼고 싶은 쪽이 몇 개 안 되면 페이지 삭제에 번호만 적는 게 더 빨라요.

⚠️ 정리하기 전에 알아 둘 것

  • 📁 원본부터 복사: 아이폰 미리보기와 맥 미리보기는 바로 같은 파일에 저장돼요.
  • 🔏 전자서명이 들어간 PDF(공동인증서 서명, 전자계약서 등)는 페이지를 바꾸면 '서명 후 문서가 바뀌었다'고 표시될 수 있어요. 이런 파일은 고치지 말고 받은 그대로 내세요.
  • 🔢 SlimIO 미리보기 카드의 번호는 원래 쪽 번호라, 순서를 바꾸면 1·3·2처럼 보여요. 저장하면 1쪽부터 차례로 이어져요.
  • 📦 정리했는데도 크면 메일 첨부용 PDF 줄이기로 한 번 더 줄이세요.

PDF를 사진으로 바꾸는 법은 이 블로그의 'PDF JPG 변환' 글에, 사진 여러 장을 PDF로 묶는 법은 사진 여러 장 PDF 하나로 합치는 법에 정리해 두었어요. 서류 정리 깔끔하게 끝내세요! 📂
