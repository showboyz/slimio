과제나 결과보고서를 다 만들고 나서 "쪽번호 넣어서 PDF로 내세요"라는 공지를 뒤늦게 본 적 있나요? 😅 원본 한글 파일이 있으면 금방이지만, 여러 서류를 이미 PDF 하나로 합쳤거나 스캔본이 섞여 있으면 어디서 번호를 넣어야 할지 막막해요.

그래서 원본이 있을 때와 PDF만 남았을 때를 나눠서 쪽번호 넣는 법을 정리했어요. 표지에는 번호를 빼고 둘째 장부터 1을 붙이는 방법, 그리고 실제 PDF에 넣어 본 결과까지 보여 드릴게요. 📝

⏱ 3줄 요약
1️⃣ 한글·워드 원본이 있으면 원본에서 번호를 넣고 PDF로 저장하는 게 가장 깔끔해요
2️⃣ 여러 파일을 합친 PDF나 스캔본은 PDF에 직접 넣어야 해요 (무료 브라우저 도구로 전체 페이지 한 번에)
3️⃣ 표지는 '1페이지 건너뛰기'로 비우면 둘째 장이 1쪽이 돼요

워드 원본 있음삽입 → 페이지 번호 → PDF로 저장첫 페이지를 다르게 지정

📝 한글(HWP) 원본이 있을 때

메뉴에서 쪽 → 쪽 번호 매기기(단축키 Ctrl+N, P)를 누르고 번호 위치와 모양을 고르면 돼요. 위치는 위·아래와 왼쪽·가운데·오른쪽 조합 6가지에, 양면 인쇄용 '홀짝수 쪽 바깥쪽·안쪽'까지 모두 10가지예요. 줄표 넣기를 켜면 -3- 처럼 번호 양옆에 줄표가 붙어요.

표지에서 번호를 빼려면 두 단계가 필요해요.
① 표지에 커서를 두고 쪽 → 감추기를 눌러 감출 내용에서 쪽 번호를 고르세요. 그 쪽의 번호만 안 보여요.
② 그런데 감추기만 하면 둘째 장이 '2'로 시작해요. 둘째 장에 커서를 두고 쪽 → 새 번호로 시작에서 번호 종류를 쪽 번호로, 시작 번호를 1로 바꾸면 둘째 장부터 1이 돼요.

다 됐으면 파일 → PDF로 저장하기로 내보내면 번호가 그대로 들어가요.

💻 워드 원본이 있을 때

삽입 → 페이지 번호에서 위치와 스타일을 고르면 모든 쪽에 번호가 들어가요. 표지 번호를 없애려면 머리글이나 바닥글을 두 번 눌러 편집 화면을 연 뒤 '첫 페이지를 다르게 지정'을 체크하고, 첫 쪽에 남은 번호를 지우세요.

이렇게만 하면 둘째 장은 '2'로 보여요. 둘째 장을 1로 시작하고 싶다면 삽입 → 페이지 번호 → 페이지 번호 서식에서 시작 번호를 0으로 바꾸면 돼요. 표지가 0쪽이 되고(숨겨져 있으니 안 보여요) 둘째 장이 1쪽이 되는 원리예요. 마지막으로 다른 이름으로 저장에서 형식을 PDF로 고르면 끝이에요.

📄 PDF만 남았을 때가 문제예요

성적증명서, 신청서, 영수증 스캔본처럼 출처가 다른 서류를 PDF 하나로 묶었다면 원본 문서가 하나가 아니라서 위 방법을 쓸 수 없어요. 이럴 땐 PDF 위에 번호를 직접 얹어야 해요.

  • 💳 Adobe Acrobat: 편집 → 머리말 및 꼬리말 → 추가에서 번호 형식과 시작 번호를 정할 수 있어요. 다만 무료 Acrobat Reader는 PDF 보기·인쇄·공유용이고, PDF를 고치는 편집 기능은 유료 Acrobat Standard부터 들어 있어요.
  • ☁️ Adobe 온라인 도구: 무료로 쓸 수 있지만 파일을 Adobe 서버에 올리고, 안내에 따르면 로그인하지 않으면 한 번만 작업할 수 있어요.
  • 📱 휴대폰·맥 기본 앱: 아이폰·갤럭시 기본 앱과 맥 미리보기 공식 설명서에서는 쪽번호를 자동으로 매기는 기능을 찾지 못했어요. 글상자로 한 쪽씩 숫자를 적을 수는 있지만 쪽이 많으면 번거롭고 위치도 들쭉날쭉해져요.

✂️ 브라우저에서 한 번에 넣기

그래서 제가 직접 만들어 운영하는 무료 도구 SlimIO에 쪽번호 기능을 넣어 두었어요. 회원가입 없이 쓰고, PDF가 서버로 올라가지 않고 브라우저 안에서만 처리돼요. 휴대폰에서도 돼요. 🙌

1️⃣ PDF 페이지 번호 넣기 (SlimIO)를 열고 PDF를 올리세요.
2️⃣ 위치(위·아래 × 왼쪽·가운데·오른쪽), 형식, 글자 크기를 고르고, 표지가 있으면 앞 페이지 건너뛰기 → 1페이지 건너뛰기(표지)를 고르세요.
3️⃣ 페이지 번호 넣기를 누르고 PDF를 내려받으면 끝이에요. ✅

형식은 '1', 'Page 1', '1 / 10', 'Page 1 of 10' 네 가지예요. 시작 번호는 0~3에서 고를 수 있어서, 목차까지 빼고 싶으면 '2페이지 건너뛰기'를 쓰면 돼요.

이런 서류라면추천 설정
과제·결과보고서 (표지 있음)아래 가운데 · '1' · 1페이지 건너뛰기
여러 서류를 합친 제출 묶음아래 오른쪽 · '1 / 10' — 빠진 쪽이 없다는 게 한눈에 보여요
표지·목차가 있는 긴 문서2페이지 건너뛰기 · 시작 번호 1

🔬 직접 넣어 봤어요

가상 '동네 텃밭 운영 결과보고서'(표지+본문 8쪽)와, 신청서 2쪽에 영수증·행사 사진 스캔 4쪽을 붙인 가상 정산 서류 묶음으로 실험했어요.

눈여겨볼 점 세 가지예요.

  • 🔢 표지를 건너뛰면 전체 쪽수에서도 표지가 빠져요. 그래서 '9쪽 중 2쪽'이 아니라 '1 / 8'로 자연스럽게 시작해요.
  • 🧾 한글·워드로는 손댈 수 없는 스캔 이미지 쪽에도 번호가 들어갔어요.
  • 🔍 번호는 그림이 아니라 글자로 들어가서, 번호를 넣은 뒤에도 본문 글자를 그대로 복사·검색할 수 있었어요. 용량도 늘지 않았고, 이번 실험에서는 저장하면서 오히려 조금 줄었어요.

⚠️ 번호 넣기 전에 알아 둘 것

  • 🗂 순서 정리와 빈 쪽 삭제를 먼저 하세요. 번호를 넣은 뒤에 쪽을 빼거나 옮기면 번호가 따라 바뀌지 않아서 다시 넣어야 해요. 정리하는 법은 이 블로그의 'PDF 페이지 삭제·회전 저장' 글에 모아 두었어요.
  • 📎 여러 파일을 묶을 거라면 PDF 합치기로 먼저 합친 다음 번호를 한 번만 넣으세요. 파일마다 따로 넣으면 1이 여러 번 나와요.
  • 👀 원래 쪽번호가 찍혀 있는 PDF라면 같은 자리에 넣었을 때 겹쳐 보일 수 있어요. 이럴 땐 위치를 위 오른쪽처럼 비어 있는 곳으로 바꾸세요.
  • 🔏 공동인증서 서명이나 전자계약처럼 전자서명이 들어간 PDF는 번호를 넣는 것도 문서를 고치는 일이라 '서명 후 문서가 바뀌었다'고 표시될 수 있어요. 받은 그대로 내세요.
  • 📦 번호를 넣은 뒤 제출 칸 용량에 걸리면 PDF 용량 줄이기로 한 번 더 줄이면 돼요.

종이 서류를 휴대폰으로 찍어 PDF 하나로 만드는 법은 사진 여러 장 PDF 하나로 합치는 법에 정리해 두었어요. 번호까지 깔끔하게 넣고 제출 마무리하세요! 📂
