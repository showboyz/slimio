사진을 올리려는데 "JPG 파일만 등록할 수 있어요"라고 막힌 적 있으시죠? 😥 휴대폰 스크린샷은 PNG로 저장되는 경우가 많고, 웹에서 받은 사진은 WebP일 때도 있어서 이런 일이 생각보다 자주 생겨요.

그래서 PNG와 JPG가 뭐가 다른지, 아이폰·갤럭시·PC에서 어떻게 바꾸는지 정리하고, 예시 파일 4개를 실제로 바꿔서 용량·글자 화질·투명 배경이 어떻게 되는지 확인했어요. 📝

⏱ 3줄 요약
1️⃣ 사진은 JPG, 글자·로고·스크린샷은 PNG가 기본이에요
2️⃣ PNG로 저장된 사진을 JPG로 바꾸니 18.5MB → 1.95MB, 89% 줄었어요
3️⃣ 투명 배경은 JPG가 되면 흰 배경이 되고, WebP를 JPG로 바꾸면 오히려 커질 수 있어요

🤔 PNG와 JPG, 뭐가 달라요?

항목PNGJPG(JPEG)
저장 방식무손실 (원본 그대로)손실 압축 (조금 버리고 작게)
투명 배경돼요안 돼요
잘 맞는 것스크린샷, 글자, 로고, 도표사진
사진 용량아주 큼작음

MDN(웹 개발 문서)도 같은 기준을 권해요. JPG는 사진에 잘 맞지만 도표나 글자에 쓰면 결과가 아쉬울 수 있고, 스크린샷·로고·선 그림은 PNG 같은 무손실 형식이 낫다고 해요. 그리고 JPG에는 투명 배경(알파)이 없어서, 투명해야 하는 이미지는 PNG로 둬야 해요.

📱 아이폰: 미리보기 앱에서 내보내기

iOS 26부터 생긴 미리보기 앱에서 사진 파일을 열고, 파일 이름 옆 동작 메뉴 → 내보내기를 누르면 형식을 고를 수 있어요. HEIC·JPEG·PDF·PNG·TIFF 중에 고르고 완료 → 저장하면 돼요. JPEG는 '크기' 막대로 용량과 화질을 조절할 수 있고, PNG는 '알파'를 끄면 투명한 부분이 채워져요.

  • 📸 스크린샷 형식: 설정 → 일반 → 화면 캡처에서 SDR로 두면 PNG, HDR로 두면 HEIF로 저장된다고 Apple 설명서에 나와 있어요.
  • 📷 카메라 사진: 설정 → 카메라 → 포맷에서 높은 호환성을 고르면 앞으로 찍는 사진이 HEIC 대신 JPEG로 저장돼요.

📱 갤럭시: 캡처 형식은 설정에서

갤럭시 스크린샷 형식은 설정 → 유용한 기능 → 화면 캡처 및 화면 녹화에서 캡처 형식(JPG·PNG)을 바꿀 수 있어요. 앞으로 찍는 캡처에 적용돼요.

이미 저장된 사진은 조금 번거로워요. 갤러리 편집의 다른 파일로 저장은 사본을 만드는 기능인데, 삼성전자서비스 안내에 형식을 고르는 방법은 나와 있지 않아요. 이미 있는 PNG를 JPG로 바꾸려면 아래 브라우저 도구가 가장 간단해요.

💻 PC: 그림판·미리보기

  • 🪟 윈도우: 그림판으로 열어 저장할 때 형식을 고를 수 있어요(PNG·JPEG·BMP·GIF). 다른 이름으로 저장에서 JPEG를 고르면 돼요.
  • 🍎 맥: 미리보기에서 파일 → 내보내기를 누르고 포맷을 JPEG나 PNG로 고르세요. 여러 장이면 Finder에서 골라 빠른 동작 → 이미지 변환이 편해요.

🔬 직접 바꿔 봤어요: 예시 파일 4개

가상의 시간표 앱 스크린샷(PNG), PNG로 저장된 휴대폰 사진, 투명 배경 동아리 로고(PNG), 웹에서 받은 행사 사진(WebP)을 준비했어요. 제가 만든 무료 도구 SlimIO에서 JPG, 원래 크기(픽셀) 그대로로 한 번에 바꿨어요.

파일바꾸기 전JPG로 바꾼 뒤
PNG로 저장된 사진18.47MB1.95MB (−89%)
스크린샷 (글자 많음)222.6KB136.3KB (−39%)
투명 배경 로고75.9KB42.2KB, 배경이 흰색으로
WebP 사진123.8KB149.0KB (+20%)
  • 📸 사진은 JPG가 압도적이에요. 같은 픽셀인데 9분의 1이 됐고, 눈으로는 차이를 찾기 어려웠어요.
  • 🔤 스크린샷은 덜 줄고 글자에 티가 나요. 2배로 확대하면 JPG 글자 가장자리에 자잘한 얼룩이 보였어요. 업로드 칸이 JPG만 받는 게 아니라면 스크린샷은 PNG 그대로가 나아요.
  • 🟨 투명 배경은 사라져요. 노란 배경에 올려 보니 PNG 로고는 자연스러운데, JPG는 흰 네모가 생겼어요. 로고·서명처럼 다른 문서 위에 올릴 이미지는 PNG로 두세요.
  • 🌐 WebP를 JPG로 바꾸면 커질 수 있어요. MDN에 따르면 WebP는 같은 사진을 JPG보다 25~35% 작게 저장하는 형식이에요. 사이트가 WebP를 안 받을 때만 바꾸세요.

🔁 SlimIO로 한 번에 바꾸기 (여러 장도 OK)

위 실험은 제가 직접 만들어 운영하는 무료 도구 SlimIO로 했어요. 사진이 휴대폰·PC 밖으로 나가지 않고 브라우저 안에서 바뀌고, 사진 속 위치정보(EXIF)도 지워져요. 🙌

1️⃣ 사진 용량 줄이기 (SlimIO)를 열고 바꿀 사진을 고르세요. 여러 장을 한꺼번에 골라도 돼요.
2️⃣ 목표 용량은 '제한 없음', 크기 조절은 '원래 크기 유지', 저장 형식은 'JPG'로 고르세요. 업로드 칸에 '1MB 이하' 같은 제한이 있다면 목표 용량을 그 숫자로 고르면 형식과 용량을 한 번에 맞춰 줘요.
3️⃣ 사진 용량 줄이기를 누르고 하나씩 받거나 전체 다운로드(ZIP)로 받으세요. ✅

✅ 알아 두면 좋은 것

  • ✏️ 파일 이름만 .jpg로 고치는 건 변환이 아니에요. 이름 끝만 바뀌고 속은 PNG 그대로라서, 사이트에 따라 오류가 나거나 열리지 않을 수 있어요.
  • 🔄 JPG를 PNG로 바꿔도 화질은 돌아오지 않아요. 이미 버려진 정보는 그대로 없고 용량만 커져요.
  • 🪟 윈도우에서 WebP가 안 열리면 Microsoft Store의 'WebP Image Extension'을 설치하면 사진 앱과 탐색기에서 볼 수 있어요.

사진을 50KB·100KB처럼 정해진 용량에 맞춰야 한다면 사진 용량 50KB·100KB 맞추는 법을, 사진 여러 장을 PDF 하나로 묶어야 한다면 사진 여러 장 PDF 하나로 합치는 법을 참고하세요. 형식 때문에 업로드가 막히는 일, 이제 없게요! 🙌
