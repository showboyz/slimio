출장을 다녀와서 경비 정산을 하려는데 경영지원팀에서 이렇게 말하더라고요. "정산서랑 증빙은 PDF 한 파일로 올려 주세요." 😮 제 손에 있는 건 정산서 PDF, 카드사에서 받은 이용내역 PDF, 휴대폰으로 찍은 영수증 PDF 두 장. 파일이 네 개예요.

다음에서 'pdf 합치기'를 검색하면 '알pdf 합치기', 'pdf 합치기 프로그램 다운로드'가 같이 떠요. 설치형 프로그램을 쓰는 분이 그만큼 많다는 뜻이죠. 그런데 회사 PC라 설치가 막혀 있거나, 휴대폰에서 바로 끝내고 싶을 때도 있잖아요. 그래서 설치 없이 합치는 방법을 실제로 해 보면서 정리했어요. 해 보니 버튼 누르는 것보다 중간에 막히는 지점을 아는 게 더 중요했어요. 📝

🔒 잠긴 PDF가 안 들어갈 때

PDF 잠금은 두 종류예요. 둘 다 '잠긴 파일'처럼 보이지만 푸는 방법이 달라요.

종류이런 파일푸는 법
열기 암호열 때마다 암호 창이 떠요 (명세서 등)아는 암호를 넣고 잠금 없는 사본 만들기
권한 암호열리긴 하는데 인쇄·복사·편집이 막혀요암호 입력 없이 제한만 풀기

실험에서는 PDF 비밀번호 해제로 하나씩 풀었어요. 정산서는 올리자마자 '암호 없이 열리지만 사용 제한이 걸린 PDF'라고 알려 줬고, 버튼만 누르니 제한이 풀렸어요(68.9KB → 69.0KB). 카드 이용내역은 예시 암호 850315를 넣자 바로 열렸어요(57.0KB → 57.1KB). 잠금만 걷어 내는 거라 용량도 내용도 거의 그대로예요.

💡 명세서 암호는 카드사·은행마다 달라요. 메일이나 문자에 어떤 번호로 열리는지 같이 안내돼요. 암호를 모르면 어떤 도구로도 풀 수 없으니 보낸 곳에 물어보세요. 또 전자서명이 든 PDF(진본 확인이 되는 전자증명서 같은 것)는 잠금을 풀면 파일이 다시 저장돼서 서명 확인을 통과하지 못해요. 이런 서류는 원본 그대로 내야 하는지 먼저 확인하세요.

🔃 순서 바꾸기: 나중에 넣은 파일은 맨 아래로

잠금 푼 사본 두 개를 같은 화면에 추가했더니 목록 3번, 4번으로 붙었어요. 새로 고른 파일은 늘 끝에 들어가요. 정산 규정 순서(정산서 → 카드 내역 → 영수증)에 맞추려고 정산서의 ▲를 두 번, 카드 내역의 ▲를 두 번 눌렀어요. 잘못 넣은 파일은 ✕로 빼면 되고요.

  • 🔢 파일 이름 앞에 01_, 02_처럼 번호를 붙여 두면 목록에서 헷갈리지 않아요
  • 📋 제출처가 순서를 정해 줬다면 그대로, 없다면 신청서·정산서 같은 본 서류를 맨 앞에 두세요
  • 🔍 합친 뒤에는 첫 장과 마지막 장만이라도 열어서 확인하세요

📦 합쳤더니 용량이 커졌을 때

순서를 맞추고 합치니 파일 4개, 5쪽, 2.12MB가 나왔어요. 네 파일을 더한 값이 2,226,904바이트, 합친 파일이 2,225,837바이트로 거의 같아요. 합치기는 페이지를 이어 붙일 뿐 줄여 주지는 않는다는 뜻이에요. 그 대신 화질도 그대로고, 정산서와 카드 내역의 글자도 그대로 선택됐어요.

무게를 나눠 보면 글자 서류 두 개는 합쳐도 126KB인데, 영수증 사진 PDF는 하나에 1MB 안팎이었어요. 업로드 칸이 '1MB 이하'라면 합친 파일을 한 번만 줄이면 돼요. 같은 파일을 PDF 1MB로 줄이기에 넣었더니 2.12MB → 546.8KB가 됐어요. 쪽 순서와 글자는 그대로이고 영수증 사진만 작아졌는데, 확대해도 금액이 또렷했어요. ✅

⚠️ 파일마다 따로 줄이고 합치는 것보다 합친 뒤 한 번 줄이는 게 편해요. 업로드 제한은 결국 마지막에 내는 파일 하나에 걸리니까, 그 파일 크기만 맞추면 되거든요. 참고로 합치기와 비밀번호 해제는 브라우저 안에서만 처리되고, 압축은 글자를 살리는 단계에서 파일을 서버로 보냈다가 끝나면 바로 지워요.

📱 아이폰·갤럭시에서 합치기

아이폰은 iPhone 사용 설명서(iOS 26·27)에 나온 미리보기 앱으로 돼요. 맨 앞에 둘 PDF를 미리보기로 열고 → 썸네일 보기 → 썸네일을 길게 터치 → 파일에서 삽입을 누른 뒤 붙일 PDF를 고르면 돼요. 들어간 페이지 위치는 썸네일을 길게 눌러 메뉴가 뜰 때 위아래로 끌어서 옮겨요.

갤럭시는 삼성전자서비스의 삼성 노트 안내에 'PDF로 저장'은 있지만 여러 PDF를 합치는 방법은 찾지 못했어요. 삼성 노트의 'PDF 가져오기'도 2026년 4월 업데이트 뒤 '노트 생성' 버튼을 길게 누르는 방식으로 바뀌었다고 삼성 멤버스 노트 담당자가 답했을 만큼 메뉴가 자주 바뀌어요. 그래서 갤럭시는 크롬이나 삼성 인터넷으로 브라우저 도구를 여는 게 제일 덜 헤매요. 위 실험 화면도 휴대폰 폭(400px)으로 찍은 거예요. 📲

💻 맥·윈도우 PC에서 합치기

맥은 Finder에서 합칠 파일을 넣고 싶은 순서대로 Command-클릭으로 하나씩 고른 뒤, Control-클릭 → 빠른 동작 → PDF 생성을 누르면 끝이에요. Apple 설명서에 고른 순서 그대로 들어간다고 적혀 있고, 새 파일 이름은 처음 고른 파일 이름을 따라가요. 미리보기 앱에서 한 PDF의 썸네일을 다른 PDF 사이드바로 끌어 넣는 방법도 있는데, 이건 바뀐 내용이 원본에 자동 저장돼요. 먼저 파일 → 복제로 사본을 만들어 두세요.

윈도우의 기본 PDF 뷰어인 엣지에는 보기·인쇄, 양식 채우기, 필기, 강조, 소리 내어 읽기 같은 기능이 있지만 Microsoft 기능 안내에 합치기는 없어요. 알PDF·한PDF 같은 설치형 프로그램을 써도 되고, 가끔 한 번 합칠 거라면 브라우저 도구가 빨라요.

🙋 자주 묻는 질문

Q. 무료로 몇 개까지 합칠 수 있어요?
👉 SlimIO 합치기는 개수 제한이 없고, 회원가입 없이 하루 20회까지 무료예요. 결과 파일에 워터마크도 안 붙어요. 아주 큰 파일을 많이 넣으면 기기 사양에 따라 느려질 수 있어요.

Q. 합치면 화질이 떨어지나요?
👉 합치기만 해서는 안 떨어져요. 실험에서도 용량이 더한 값 그대로였고 글자도 선택됐어요. 화질이 바뀌는 건 용량을 줄일 때예요.

Q. 받은 파일 이름이 이상해요
👉 slimio_merged.pdf로 저장돼요. '김샘플_10월출장정산.pdf'처럼 바꿔서 내면 받는 쪽도 찾기 쉬워요.

Q. 사진(JPG)도 같이 넣을 수 있나요?
👉 합치기는 PDF끼리만 돼요. 사진은 JPG → PDF에서 먼저 PDF로 만든 다음 넣으세요. 실험의 영수증도 사진 한 장짜리 PDF였어요.

합친 파일을 더 작게 만들어야 한다면 PDF 용량 줄이기 글에서 원리부터 볼 수 있어요. 정산서에 도장까지 찍어야 한다면 PDF 도장 찍기 글도 같이 보세요. 서류 제출, 한 파일로 깔끔하게 끝내세요! 📎✨
