"신청서에 서명해서 PDF로 보내 주세요~" 📩

이 말 들으면 보통 이렇게 되죠. 프린트 → 펜으로 서명 → 스캔 → 다시 PDF… 😩 프린터가 없으면 편의점까지 가야 하고요.

오늘은 프린터 없이, 1~2분 만에 끝내는 방법을 정리했어요. 종이에 쓴 내 진짜 서명을 배경 없는 투명 PNG로 만들고, 그걸 PDF 서명란에 바로 넣는 방법이에요. ✨

⏱ 3줄 요약
1️⃣ 흰 종이에 서명하고 폰으로 찰칵 📷
2️⃣ 서명 이미지 만들기에 올리면 배경이 사라진 투명 PNG 완성
3️⃣ "이 서명으로 PDF에 서명하기" → 서명란에 끌어다 놓고 저장 → 끝! 🎉

🤔 왜 '투명 PNG'여야 할까요?

서명 사진을 그대로 문서에 붙이면 종이의 회색 배경과 그림자가 네모나게 같이 붙어요. 누가 봐도 "사진 붙였네" 싶죠. 😅 배경을 투명하게 만들면 서명 선만 문서 위에 자연스럽게 얹혀서, 진짜 펜으로 쓴 것처럼 보여요.

  • 🖼 JPG — 배경이 항상 흰색이에요. 원서 사이트 업로드용(10~20KB 등)으로 좋아요.
  • 🫥 PNG (투명) — 배경이 없어요. 문서·계약서에 넣을 때 가장 깔끔해요.

✍️ 따라 하기

제가 직접 만들어 운영하는 무료 도구 SlimIO로 해 볼게요. 🙌

  • 💸 완전 무료, 회원가입 없음
  • 🔒 서명과 문서가 서버로 올라가지 않아요 (브라우저 안에서만 처리)
  • 📱 폰에서도 그대로 돼요

1️⃣ 서명 사진 올리기 (또는 직접 그리기)

서명 이미지 만들기 페이지에서 📷 종이 서명 사진 탭을 고르고, 종이에 쓴 서명을 찍은 사진을 올려 주세요. 펜이 없다면 ✍️ 직접 그리기 탭에서 손가락으로 그려도 돼요. 저장 형식은 PNG — 투명 배경이 기본이에요.

2️⃣ 투명 PNG 확인하고 다운로드

서명 이미지 만들기를 누르면 종이·그림자·책상이 싹 사라지고 서명 선만 남아요. 체크무늬로 보이는 부분이 투명한 곳이에요. 파일로 받아 두고 싶으면 서명 다운로드를 누르면 돼요.

💡 여기서 바로 PDF에 넣고 싶다면?
결과 아래 "✍️ 이 서명으로 PDF에 서명하기"를 누르세요. 방금 만든 서명을 들고 PDF 서명 화면으로 넘어가요. 다시 그릴 필요가 없어요! 👍

3️⃣ PDF 올리고 서명란에 끌어다 놓기

서명할 PDF를 고르고 + 이 페이지에 서명 넣기를 누르면, 서명이 화면에 나타나요. 끌어서 서명란으로 옮기고, 초록색 모서리를 끌어 크기를 맞추면 돼요. 여러 페이지에 서명이 필요하면 다음 페이지 →로 넘어가서 똑같이 하면 되고요.

4️⃣ 서명하고 다운로드 → 끝!

서명하고 다운로드를 누르면 서명이 들어간 PDF가 저장돼요. 프린터도, 스캐너도 필요 없었죠? 🎉

예시 문서와 가상 서명으로 만든 결과예요.

📸 종이 서명, 이렇게 찍으면 더 깨끗해요

  • 📄 줄 없는 흰 종이에, 🖊 검은색이나 진한 파란색 펜으로
  • ☀️ 밝은 곳에서, 폰 그림자가 서명에 드리우지 않게 바로 위에서
  • 🔍 서명이 사진의 대부분을 차지하게 가까이 — 나머지는 자동으로 잘라 줘요
  • 🪵 책상이 같이 찍혀도 괜찮아요. 종이 밖은 알아서 지워요

🙋 자주 묻는 질문

Q. 이렇게 넣은 서명도 효력이 있나요?
👉 신청서, 동의서, 견적서처럼 일상적인 서류에는 서명 이미지가 흔히 쓰여요. 다만 인증서 기반의 전자서명과는 달라요. 법적으로 꼭 전자서명이 필요한 문서라면 받는 쪽에 먼저 확인해 보세요.

Q. 도장도 넣을 수 있나요?
👉 네! PDF 서명 화면의 이름 입력 탭에서 이름을 적고 빨간 원형 스타일을 고르면 도장이 만들어져요. 실제 도장을 찍은 사진을 이미지 올리기로 넣어도 돼요. 🔴

Q. 원서 사이트에 서명을 '10~20KB JPG'로 올려야 해요.
👉 서명 이미지 만들기에서 저장 형식을 JPG, 파일 용량을 10~20KB로 바꾸면 돼요. 크기(예: 140×60픽셀)도 직접 입력할 수 있어요.

Q. 내 서명이 어딘가에 저장되진 않나요?
👉 서명 사진과 PDF는 브라우저 안에서만 처리되고 서버로 전송되지 않아요. 창을 닫으면 그대로 사라져요. 🔒
