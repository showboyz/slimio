"견적서에 직인 찍어서 PDF로 보내 주세요~" 📩

이 말 들으면 또 시작이죠. 프린트 → 도장 쾅 → 스캔 → 다시 PDF… 😩 사무실 밖이거나 프린터가 없으면 더 막막하고요.

오늘은 프린터 없이 PDF에 도장을 넣는 두 가지 방법을 정리했어요. 도장이 없어도 이름으로 빨간 도장을 만들 수 있고, 회사 직인을 사진으로 찍어서 넣을 수도 있어요. ✨

⏱ 3줄 요약
1️⃣ PDF 서명·도장 넣기에 PDF 올리기
2️⃣ 이름 입력 → 빨간 원형 도장 고르기 (또는 이미지 올리기로 직인 사진)
3️⃣ (인) 자리로 끌어다 놓고 → 서명하고 다운로드. 끝! 🎉

🔴 방법 1. 도장이 없다면? 이름으로 도장 만들기

제가 직접 만들어 운영하는 무료 도구 SlimIO로 해 볼게요. 🙌 예시는 직접 만든 가상의 견적서예요.

  • 💸 완전 무료, 회원가입 없음
  • 🔒 PDF와 도장이 서버로 올라가지 않아요 (브라우저 안에서만 처리)
  • 📱 폰에서도 돼요

1️⃣ PDF 올리고 이름 입력

PDF 서명·도장 넣기 페이지에 PDF를 끌어다 놓으세요. 이름 입력 탭에서 이름을 적으면 손글씨 서명 4가지와 빨간 원형 도장이 나와요. 도장을 고르고 + 이 페이지에 서명 넣기를 누르세요.

세 글자 이름은 세로 한 줄로, 두 글자·네 글자도 도장답게 알아서 배치해 줘요. 😎

2️⃣ (인) 자리로 끌어다 놓기

도장이 문서 위에 나타나면 (인) 자리로 끌어 옮기세요. 크기는 초록색 모서리를 끌어서 맞추면 돼요. 글자 위에 겹쳐도 아래 글자가 비쳐 보여서 진짜 찍은 것처럼 자연스러워요.

🏢 방법 2. 회사 직인·실제 도장을 넣고 싶다면

3️⃣ 직인 찍은 종이를 사진으로 올리기

흰 종이에 직인을 꾹 찍고 폰으로 찰칵 📷 그다음 이미지 올리기 탭에서 사진을 고르세요. 흰 배경 자동 제거가 켜져 있어서 종이는 사라지고 빨간 인영만 남아요. 사진 가장자리가 어둡게 나와도 괜찮아요.

네모난 빨간 직인은 알아서 직인 크기(약 2.3cm)로 들어가요. 회사 이름 끝 글자에 살짝 걸치게 놓으면 딱 우리가 아는 그 모양! 직인 스캔 파일(PNG·JPG)이 이미 있다면 그대로 올려도 돼요.

4️⃣ 서명하고 다운로드 → 끝!

서명하고 다운로드를 누르면 도장이 들어간 PDF가 저장돼요. 프린터도 스캐너도 필요 없었죠? 🎉

가상의 업체로 만든 예시 문서예요.

📸 직인 사진, 이렇게 찍으면 더 깨끗해요

  • 📄 줄 없는 흰 종이에 인주를 고르게 묻혀서 꾹
  • ☀️ 밝은 곳에서, 폰 그림자가 도장에 드리우지 않게 바로 위에서
  • 🔍 도장이 화면 가운데 오도록 가까이 — 나머지는 자동으로 잘라 줘요
  • 🗂 한 번 만든 결과 PDF를 보관해 두면 다음엔 더 빨라요

🙋 자주 묻는 질문

Q. 이렇게 넣은 도장도 효력이 있나요?
👉 견적서, 거래명세서, 신청서처럼 일상적인 서류에는 도장 이미지가 흔히 쓰여요. 다만 인감증명서가 필요한 서류나 인증서 기반 전자서명을 요구하는 서류는 달라요. 중요한 계약이라면 받는 쪽에 먼저 확인해 보세요.

Q. 여러 페이지에 도장을 찍어야 해요.
👉 다음 페이지 →로 넘기면서 필요한 곳마다 도장을 추가하세요. 모두 한 파일에 저장돼요.

Q. 도장 크기를 바꾸고 싶어요.
👉 도장 오른쪽 아래의 초록색 모서리를 끌면 비율 그대로 커지고 작아져요. 잘못 넣었다면 ✕로 지우면 돼요.

Q. 회사 직인 파일이 외부로 나가지 않나요?
👉 PDF와 도장 이미지는 브라우저 안에서만 처리되고 서버로 전송되지 않아요. 창을 닫으면 그대로 사라져요. 🔒

Q. 손글씨 서명도 넣을 수 있나요?
👉 네! 직접 그리기 탭에서 손가락이나 마우스로 그리면 돼요. 종이에 쓴 서명을 깨끗하게 만들고 싶다면 이전 글 서명 이미지 만들기를 참고하세요. ✍️

이제 "도장 찍어서 보내 주세요"도 1분이면 끝! 😎 PDF 용량이 커서 메일에 안 붙는다면 PDF 용량 줄이기 글도 함께 보세요.
