# 네이버 클립 (clip.naver.com/@pdfslimio)

클립 프로필은 2026-10-30에 만들었어요 (아이디 pdfslimio, 사장님 결정). 블로그 연결은 화면에 MY플레이스만 나와서 하지 않았어요.
올리는 곳은 클립 크리에이터 PC 웹 https://clipcreators.naver.com/web (크롬 로그인 필요). PC 웹에서 올린 클립은 블로그 화면에는 안 나오고,
클립마다 '콘텐츠 링크 → 블로그'로 같은 주제 글을 붙여요.

## 만들기
- `NN-주제/spec.json`: 장면 목록(hook / specs / big / shot / end), 색, 설명(desc, 300자 안), 해시태그 5개, 연결할 글 제목 앞부분(postTitle), 카테고리(cat, 기본 교육 > 교육).
  `*글자*`는 강조색. 사실은 이미 발행된 블로그 글에서만 가져와요.
- `node lib/render.mjs NN-주제` → `NN-주제/<name>.mp4`(1080×1920, 30fps, 무음 트랙)와 cover.jpg. 장면은 `lib/clip.html`.
  클립 화면은 아래쪽(설명)과 오른쪽(버튼)이 가려져서 글자는 y 180~1450 안에 둬요.
- 도구 화면(tool.png)은 얼굴 없는 그림 인물로 실제 pdfslimio.com/ko 도구를 찍은 것(프리셋 버튼을 눌러야 중국 비자처럼 용량 하한도 맞춰져요).

## 올리기
`python3 lib/upload.py <크롬 창 id> NN-주제 ["YYYY-MM-DD HH:MM"]` — 업로드 → 설명·해시태그 → 커버 2 → 카테고리 → 블로그 글 연결 → (날짜가 있으면) 공개 예약 → 등록.
사장님이 컴퓨터를 쓰는 동안은 `naver/editor/guard.sh`로 기다려요. 달력은 날짜를 누른 뒤 달력 안의 '저장'을 눌러야 적용돼요.
AI 활용 설정은 끔(실제 사람 얼굴·목소리 합성, 사실 변형, 사실적 생성이 아님), 광고·협찬도 끔(제3자 대가 없음).
