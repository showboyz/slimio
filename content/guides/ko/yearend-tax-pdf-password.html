홈택스에서 받은 연말정산 간소화 PDF가 비밀번호를 물어서 막혔거나, 회사에서 "비밀번호 없는 파일로 다시 주세요"라는 말을 들었다면 답은 짧아요. 이 비밀번호는 내려받을 때 내가 직접 넣은 숫자 7자리예요. 국세청이 정해 준 번호도, 주민등록번호도 아니에요. 홈택스 내려받기 창의 실제 안내 문구와 국세청 매뉴얼을 직접 확인해서 정리했어요. (2026년 11월 확인)

회사에 낼 파일은 원본이 안전해요. 비밀번호를 잊었거나 회사가 암호 없는 파일을 원하면 비밀번호 없이 다시 내려받는 것이 가장 확실해요. 암호를 푼 사본은 보기·인쇄·보관용으로 쓰세요.

비밀번호는 내려받을 때 넣은 숫자 7자리예요

간소화 자료를 조회한 뒤 [한번에 내려받기]나 항목별 [PDF 다운로드]를 누르면 '소득·세액 공제 자료 내려받기' 창이 떠요. 이 창의 문서열기암호(비밀번호)설정에 체크하면 "로그인한 사용자가 입력한 번호 7자리로 자동설정 됩니다"라는 확인 창이 나오고, 번호 칸이 열려요.

  • 칸에는 숫자만, 7자리까지 들어가요. 영어나 기호는 안 돼요.
  • 7자리를 다 채우지 않으면 "비밀번호 자릿수 7자리를 입력하세요"가 뜨고 내려받기가 멈춰요.
  • 체크하지 않으면 비밀번호 없이 받아져요.

국세청 외국인 연말정산 매뉴얼(2025년 12월 기준)에도 PDF를 받을 때 비밀번호를 걸지 말지 고를 수 있고, 건다면 임의의 7자리로 정한다고 적혀 있어요.

파일 이름의 6자리는 비밀번호가 아니에요

받은 파일 이름은 기본으로 "성명(주민등록번호 앞 6자리) - 항목명.PDF" 형태예요. 이름에 생년월일 숫자가 보이니 그게 비밀번호인 줄 알기 쉬운데, 자릿수부터 달라요. 같은 창의 '개인정보 공개·비공개'도 PDF 안에 주민번호를 어떻게 찍을지(비공개면 123456-*******)를 정하는 것이라 비밀번호와는 관계없어요.

몇 년 전에 받은 파일이라면 사정이 다를 수 있어요. 홈택스 공용 스크립트에는 "주민등록번호 뒤 7자리로 자동설정"이라는 옛 안내 문구가 남아 있어요. 지금 내려받기 창은 이 문구를 쓰지 않지만, 예전 파일은 그 번호로 걸렸을 수 있어요. 언제 바뀌었는지는 공식 안내가 없어요.

비밀번호를 잊었다면 다시 내려받으세요

이 번호는 내려받는 순간 내가 넣은 숫자로만 걸려요. 확인한 국세청·홈택스 안내 어디에도 잊은 번호를 찾아 주는 메뉴는 없어요. 가장 빠른 길은 간소화 화면에서 같은 자료를 다시 조회하고, 비밀번호 체크를 끈 채 다시 받는 거예요. 1월 20일이 지났다면 발급기관의 추가·수정분까지 반영된 최종 자료로 받게 돼요.

번호가 몇 개로 좁혀진다면 하나씩 넣어 볼 수는 있어요. SlimIO는 틀린 번호를 넣어도 하루 사용 횟수가 줄지 않아요. 하지만 모르는 번호를 추측하거나 뚫어 주지는 않아요.

가족(부양가족) 자료는 이렇게 받아요

  • 자료제공동의: 가족이 홈택스 [장려금·연말정산·기부금 → 연말정산간소화 → 부양가족 자료제공동의]에서 나를 자료 받을 사람으로 넣고 동의하면, 내 간소화 화면에서 가족 자료까지 조회해 쓸 수 있어요. 휴대폰은 손택스 [전체메뉴 → 장려금·연말정산·전자기부금 → 연말정산간소화]에 있어요.
  • 가족이 직접 받은 PDF: 국세청 FAQ(2026년 1월)는 가족 자료가 화면에서 빠졌는데 세무서에 연락하기 어렵다면, 가족이 직접 내려받은 간소화 PDF를 넘겨받아 두 파일을 회사 프로그램에 한 번에 올리는 방법을 안내해요. 하나로 합치라는 말은 없어요.

가족이 비밀번호를 걸었다면 그 7자리도 함께 받아야 해요. 처음부터 비밀번호 없이 받아 달라고 부탁하는 게 서로 편해요.

회사 프로그램은 PDF를 '읽어서' 써요

국세청 매뉴얼을 보면, 회사는 홈택스의 '자료추출프로그램'을 회사 연말정산 프로그램에 미리 설치해 둬요. 근로자가 간소화 PDF를 올리면 프로그램이 파일 속 자료를 읽어 소득·세액공제신고서를 자동으로 작성해요. 전자문서진본확인센터는 이 PDF가 국세청 시스템과 시점확인(TSA)을 연계해 진본성을 확보한 전자문서라고 설명해요. 눈에 보이는 내용이 같아도 원래 파일인지가 중요한 이유예요.

홈택스 내려받기 창에도 주의 문구가 있어요.

  • PDF는 [저장]이나 [다른이름으로 저장]으로 받고, [열기]로 먼저 연 뒤 다른 이름으로 저장하지 말라고 해요. 위·변조로 인식될 수 있다는 이유예요.
  • 크롬 같은 브라우저나 아크로뱃 리더가 아닌 앱으로 열면 '미검증'이 보일 수 있어요. 제대로 저장한 파일은 미검증으로 보여도 회사에 내면 정상적으로 연말정산이 된다고 해요. 미검증 표시를 없애려고 파일을 다시 저장하지 마세요.

제출은 원본으로: 4가지 방법

  1. 회사 프로그램에 비밀번호 칸이 있으면 원본을 올리고 7자리를 넣어요. 칸이 있는지는 프로그램마다 달라서 회사에 물어보세요. 국세청도 회사 프로그램은 회사에 문의하라고 안내해요.
  2. 칸이 없거나 회사가 암호 없는 파일을 원하면 체크를 끄고 다시 내려받은 파일을 내요.
  3. 회사가 '일괄제공'을 신청했다면 홈택스에서 확인(동의)만 하면 국세청이 회사로 자료를 보내요. 파일을 주고받을 일이 없어요. 회사가 받는 압축파일에는 담당자가 정한 4자리 숫자가 걸리는데, 내 7자리와는 별개예요.
  4. 회사가 홈택스 '편리한 연말정산'을 쓴다면 '간편제출'로 간소화 자료를 회사에 바로 보낼 수 있어요.

암호 없는 사본이 필요할 때

제출과 별개로, 비밀번호 없는 사본이 편한 때가 있어요. 휴대폰에서 매번 7자리를 넣지 않고 보고 싶을 때, 인쇄할 때, 간소화에 안 나오는 안경·교복 영수증과 묶어 내 보관용으로 정리할 때예요. PDF 비밀번호 해제는 내가 아는 번호를 넣으면 qpdf(WebAssembly)로 같은 파일을 암호 없이 다시 저장해요. 파일과 번호는 브라우저 밖으로 나가지 않아요.

직접 해 봤어요: 첨부 데이터는 남았어요

실제 간소화 PDF는 로그인해야 받을 수 있어서, 비슷한 구조의 가상 예시 PDF를 만들어 시험했어요. 1쪽 문서에 XML 첨부파일(466바이트)과 제목·작성자·주제·키워드를 넣고, 숫자 7자리 비밀번호(AES-256)를 건 135.2KB 파일이에요.

  • 틀린 7자리: "이 암호로는 PDF가 열리지 않아요" 안내, 남은 횟수는 그대로
  • 맞는 7자리: 열기 암호 해제됨, 127.3KB
  • 푼 파일 점검: 쪽수와 본문 글자 그대로, 첨부 XML은 바이트 단위까지 같았고, 문서 정보 4가지도 같았어요

SlimIO로 푼 파일도 첨부 데이터는 그대로 남았어요(직접 확인). 다만 파일 고유 ID의 뒷부분이 바뀌었어요. 내용은 같아도 새로 저장된 다른 파일이라는 뜻이에요. 푼 파일이나 합친 파일을 회사 프로그램이 못 읽는다는 국세청 문구는 찾지 못했고, 읽는다는 안내도 없어요. 확인되지 않은 일이니 제출은 원본으로 하세요. 전자서명이 들어 있는 PDF를 풀면 결과 화면에 서명 확인을 통과하지 못한다는 경고도 떠요.

푸는 순서

  1. PDF 비밀번호 해제를 열고 간소화 PDF를 고르세요.
  2. "열 때 암호가 필요한 PDF예요"가 뜨면 내려받을 때 넣은 숫자 7자리를 입력하세요.
  3. PDF 비밀번호 해제를 누르고 해제된 PDF 다운로드를 누르세요. 파일 이름 끝에 _unlocked가 붙어서 원본과 섞이지 않아요.

간소화에 안 나오는 종이 영수증은 영수증 PDF 만들기로 사진을 한 파일에 묶을 수 있어요. 보관용 사본끼리 하나로 모으려면 PDF 합치기를 쓰세요. 정부24 등본처럼 6자리 암호가 걸린 전자증명서는 받는 방법과 진본 확인이 달라서 정부24 서류 PDF 저장 가이드에 따로 정리했어요.

2027년 1월 일정

국세청은 간소화 서비스를 매년 1월 15일 열고, 발급기관의 추가·수정분을 반영한 최종 확정 자료는 1월 20일부터 준다고 안내해요. 2026년에는 1월 15일(목) 개통, 1월 20일(화) 최종 확정이었고, 일괄제공은 회사가 고른 1월 17일이나 20일부터였어요. 2026년 소득을 정산하는 2027년 1월 일정은 아직 발표 전이에요(2026년 11월 확인). 발표가 나오면 국세청 보도자료로 날짜를 다시 확인하세요.
