휴대폰으로 서류를 찍어서 PDF로 만들면 용량이 금방 커져요. 한 장 한 장이 1,200만 화소 사진이기 때문이에요. 시험용으로 만든 3쪽짜리 서류 사진 PDF도 7.1MB나 됐어요. 원서 접수나 서류 제출 사이트는 1MB, 2MB처럼 용량 제한이 있는 경우가 많아서 그대로는 못 올려요. 애플 기기에는 PDF 용량을 줄이는 기본 기능이 두 가지 있어요. 맥의 미리보기와 아이폰의 단축어예요. 같은 파일로 두 기능과 SlimIO를 직접 비교해 봤어요.

2026년 10월, macOS 27 맥에서 시험용으로 만든 PDF 3개로 시험했어요. 단축어 동작은 아이폰·아이패드 단축어 앱에 있는 것과 같은 동작이고, 시험은 맥에서 했어요.

시험한 파일 3개

  • 종이 서류를 찍은 사진: 3쪽짜리 임대차 계약서를 휴대폰으로 찍은 것처럼 만든 사진(쪽마다 휴대폰 카메라에서 흔한 1,200만 화소, 3024×4032 JPEG)을 PDF 하나로 묶은 파일, 7.1MB. "PDF 용량이 너무 커요"의 대부분이 이런 파일이에요.
  • 화면 캡처: 휴대폰 화면 캡처 3장(PNG)을 PDF로 저장한 파일, 655KB.
  • 글자 위주 보고서: 글, 제목, 표, 그래프가 있는 4쪽 보고서를 브라우저에서 PDF로 저장한 파일, 101KB.

용량은 파인더와 파일 앱에 나오는 기준(1KB = 1,000바이트)이에요. '변화 없음'은 원본과 1KB도 차이가 나지 않았다는 뜻이에요(단축어의 서류 사진 칸은 같은 구성의 영어 서류로 시험했어요). 가장 눈에 띈 건 미리보기로 줄인 글자 보고서예요. 용량이 6.6배로 커졌을 뿐 아니라, 한글 글자가 모두 선으로 그린 모양으로 바뀌어서 글자를 복사하거나 검색할 수 없게 됐어요.

맥: 미리보기 '파일 크기 줄이기'

애플이 안내하는 맥 방법이에요.

  1. 미리보기 앱으로 PDF를 열어요.
  2. 파일 > 내보내기를 선택해요('PDF로 내보내기'가 아니에요).
  3. Quartz 필터 팝업 메뉴에서 파일 크기 줄이기를 골라요.
  4. 원본이 남도록 이름을 바꾸고 저장을 눌러요.

macOS 27의 이 필터 설정 파일을 열어 보면, 이미지를 1인치당 144픽셀, 긴 변 최대 2,400픽셀, JPEG 품질 0.7로 저장하라고 되어 있어요. 그래서 사진 PDF는 꽤 줄어요. 다만 비슷한 해상도인 SlimIO 결과보다 파일이 3배쯤 커요. 문제는 사진만 건드리지 않고 파일 전체를 다시 쓴다는 점이에요. 글자 PDF에서는 위처럼 오히려 나빠졌어요. 꼭 원본과 용량을 비교한 뒤에 원본을 지우세요.

같은 내보내기 창에는 '선형화된 PDF 생성', '화면에 맞게 이미지 최적화', 'JPEG로 이미지 저장' 체크상자도 있어요. 사진이 많은 파일이라면 시험해 볼 만해요. 이때도 저장한 뒤 용량을 꼭 확인하세요.

아이폰·아이패드: 단축어 'PDF 파일 크기 최적화'

아이폰의 기본 방법은 단축어 앱의 PDF 파일 크기 최적화 동작이에요. 애플이 직접 붙인 설명부터 조심스러워요. "제공된 PDF 파일의 이미지를 압축하여 파일 크기를 최적화합니다. PDF에 포함된 이미지가 이미 압축된 경우 이 작업은 파일 크기에 별다른 영향을 미치지 않을 수 있습니다."

실제로도 그랬어요. 휴대폰 사진은 이미 JPEG로 압축되어 있어서 그런지, 화면 캡처까지 세 파일 모두 크기가 그대로였어요. 그래도 내 파일로 시험해 보고 싶다면 이렇게 만들면 돼요. 새 단축어에 'PDF 파일 크기 최적화'를 넣고, 그 뒤에 '파일 저장' 동작을 넣어요. 단축어 세부사항에서 공유 시트에서 보기를 켜면, 파일 앱의 공유 버튼에서 바로 실행할 수 있어요.

아이폰·맥 어디서나: 브라우저에서 줄이기

SlimIO는 사파리에서 열리는 웹페이지라서 아이폰, 아이패드, 맥에서 방법이 같아요.

  1. pdfslimio.com/ko를 열고 상자를 눌러 PDF를 골라요. 아이폰에서는 파일 앱에서 고르면 돼요.
  2. 기본값(선명하게, 균형) 그대로 PDF 압축하기를 눌러요.
  3. 압축된 PDF 다운로드를 눌러요. 아이폰에서는 파일 앱의 '다운로드' 폴더에 저장돼요.

두 방식은 처리하는 곳이 달라요. 선명하게는 파일을 서버로 보내 Ghostscript로 사진을 줄이고 글꼴을 정리한 뒤, 결과를 돌려주자마자 파일을 지워요. 글자 보고서까지 줄어든 건 이 방식이에요. 기기 안에서만은 아무것도 올리지 않아요. 휴대폰 브라우저가 PDF 속 사진만 줄이고 글자는 그대로 둬요. 제출처에서 용량을 정해 줬다면 1MB, 500KB, 200KB 페이지를 쓰세요. 용량에 맞을 때까지 설정을 바꿔 가며 줄여 줘요.
